## 모델 카드 v4 — 구매 전환 예측

- 데이터: UCI Online Shoppers (12,330 세션, 수치형 10개 열, 양성 15.5%)
- 문제 유형: 분류 (불균형)
- 검증 방식: StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
- 모델: RandomForest(n_estimators=300, min_samples_leaf=20)
- **주 지표와 선택 근거: { 무엇을 왜 — 정확도만으로 판단하지 않는 이유를 포함 }**
- **성능(CV, 평균 ± 표준편차)**
  - 정확도 { 0.8969 ± 0.0034 } / 정밀도 { 0.7232 ± 0.0117 } / 재현율 { 00.5409 ± 0.0241 } / F1 { 0.6186 ± 0.0175 } / AP { 0.7248 ± 0.0191 }
  - **양성 비율 { 0.1547 }와 AP { 0.7248 } 비교**
- **혼동행렬(임계값 0.5): TN { 2,002 } / FP { 82 } / FN { 186 } / TP { 196 }**
  - **놓친 구매 세션 { 186 }건 ({ 49 }%)  ← 정확도만 봤을 때 보이지 않던 숫자**
- **운영점: 임계값 { 0.7584 } (용량 제약 { 500 }건)**
  - **그 지점의 정밀도 { 0.9120 } / 재현율 { 0.2390 } → 실제 구매 세션 { 456 }건 포함**
  - **선택 근거:**
    - F1 최적점은 임계값 0.36일때 0.6699로 가장 최적으로 나옴. 하지만 현 예산은 쿠폰 500장이 한정되어 있기 때문에 쿠폰을 받은 사람이 실 구매까지 이어지는 비율이 가장 높은 정밀도를 위주로 판단. 이러면 예산 낭비를 최대한 막을 수 있음
- **class_weight 보정: 채택 보류 — 근거: { AP 변화와 임계값 대안을 함께 언급 }**
  - F1 점수와 재현율은 상승함(더 적은 양성클래스에 가중치를 주어 놓쳤던 구매자들을 더 잡음) 하지만 그에 따라 비구매자를 구매자로 잘못 판단한 FP비용이 늘어남, 또한 ROC와 AP는 좋아지지 않았음 이는 **누가 더 살 것 같은가**를 순위 매기는 능력이 개선된게 하나도 없다는 뜻이다.
  즉 class_weight="balanced"가 만든 효과는 기본 모델에 임계값 조정만
  가해도 재현 가능한 수준 → 재학습 없이도 동일한 결과를 얻을 수 있어
  채택 실익이 낮음
- 한계 & 다음 단계: 모델은 기본 모델로 유지하고 비즈니스 요구(재현율 목표 / 예산 제약)에 따라 임계값을 조정하는 방식이 낫다
또한 모델에 함정이 있는게 쿠폰에 제약이 있기 때문에 어차피 쿠폰이 없어도 살 사람들에게 쿠폰을 준다라는 상황이 된다. 따라서 안 살 사람에게 쿠폰을 주는것도 낭비지만 어차피 살 사람에게 쿠폰을 주는것도 낭비라고 판단할 수 있다. 이는 쿠폰 수령 여부에 따라 구매확률차이를 예측하는 인과추론 기반 모델을 사용해야 한다.
