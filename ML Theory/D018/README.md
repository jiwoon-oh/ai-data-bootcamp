## 모델 카드 v2 — 구매 전환 예측

- 데이터: UCI Online Shoppers (12,330 세션, 수치형 10개 열만 사용)
- 문제 유형: 분류
- **베이스라인: DummyClassifier(most_frequent) = {분류}**
- **비교한 모델: Dummy / 단일 트리(기본) / 단일 트리(max_depth=5) / RandomForest / XGBoost**
- 평가 지표 & 이유: Accuracy(정확도)를 사용 그 이유는 sklearn은 기본적으로 아무 옵션도 주지 않으면 정확도만 계산함
- 정확도만 사용했을때의 문제점 : 클래스의 불균형이 꽤 크다, 쉽게 말해서 한줄로만 찍어도 꽤 높은 점수를 받을 수 있게 계산식이 되어있기 때문이다
- **성능 비교표: model_comparison_v2.csv (모델별 학습 / 테스트 / 격차)**
- 과적합 진단: 

|모델|	학습 점수|	테스트 점수	격차|
|-----|-------------|---------------|
|베이스라인|	0.845296|	0.845093|	0.000203|
|로지스틱|	0.883921|	0.879562|	0.004359|
|단일 트리|	0.999797|	0.842255|	0.157543|

- **선택한 모델과 근거:**
- 현재 데이터셋은 랜덤포레스트 모델이 가장 높은 정확도를 보였다.
- 정확도 : 0.8957이 나왔고 격차는 0.1040으로 약간 높지만 개별트리(max_depth = 5)보다는 정확도가 높은 측면에서 선택
- **피처 중요도 상위 3개와 해석:**
- PageValues는 0일때 구매율이 고작 3.8%에 불과하지만 0초과인 그룹은 56%나 구매했다, 여기서 0은 페이지의 가치를 뜻한다. size는 보면 9600명으로 대부분 이 그룹에 속하지만 거의 안사고 2730명만 산다. 
- ExitRates는 이탈율인데 이탈율이 낮을때 23%의 구매율을 보이고 이탈율이 높은 그룹은 구매율이 7%에 머무르는것을 확인할 수 있다
- ProductRelated는 제품 관련 페이지에 오래 머문 그룹일수록 구매율이 22%이고 낮을수록 8.6%밖에 안되는것을 확인할 수 있다
- **중요도의 한계 명시: 방향성 부재 / 개별 설명 불가 / 인과 아님**
- 한계 & 다음 단계: 
  - 상위 세 피처들 모두 사용자의 행동기반지표라는 공통점이 있다. 반면 하위권에 머무른 피처들은 캘린더,카테고리성 변수라 개별 구매자의 구매 여부를 가르는 힘이 약하다
  - 상위 피처들간 상관관계를 따져보아야 한다.
