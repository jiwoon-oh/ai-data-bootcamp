## 3. 데이터 관찰에서 본 핵심 사실

- 운임은 **강한 우편향**이라 평균이 중앙값의 두 배 → 보고에는 *중앙값*도 함께
- 진료 방문 횟수는 **과대산포**(분산 ≫ 평균) → 포아송 가정 기각
- 펭귄 체중은 **다봉(종 혼합)** — 종을 나누면 각각 단봉·정규에 가까워짐

## 4. 다음 분석 제안

- 집단 평균 비교(예: 성별 운임)에 t-test/ANOVA 적용 시 **로그 변환 또는 비모수**
- 비율 분석은 **카이제곱 + 베타 사후**
- 체중처럼 다봉인 변수는 _집단(종) 분리 후_ 별도 분석 권장
