# Part 1 [비즈니스 관점 판단]

  - fare  CV = 1.54  /  total_bill CV = 0.45

## titanic fare가 훨씬 예측하기 어렵다.

근거 1 – 절대적 흩어짐
  fare: 평균 32원에 표준편차 50원 → 평균보다 표준편차가 더 크다.
        실제 운임은 0원(유아 무료)부터 512원(1등석 귀족)까지 존재.
  bill: 평균 20달러에 표준편차 9달러 → 평균의 절반 수준. 비교적 밀집.

근거 2 – CV(변동계수)로 스케일 제거 후 비교
  CV = 표준편차 / 평균 → 단위·크기와 무관한 '상대적 흩어짐'
  fare CV 1.54 vs bill CV 0.45 → fare가 3.4배 더 불안정

근거 3 – 합성 예시(A vs B)로 직관 확인
  평균 동일(20)인데 σ=2인 A는 ±5 이탈 확률이 1.6%에 불과하지만,
  σ=10인 B는 같은 이탈 확률이 39.4%나 된다.
  → 평균은 같아도 분산이 크면 '다음 값이 평균 근처에 올 것'이라는
    예측 자체가 신뢰할 수 없게 된다.

실무 시사점
  - fare처럼 CV가 큰 변수는 '평균'만 보고하면 오해를 부른다.
    중앙값 + IQR, 또는 객실 등급별 세분화가 필수.
  - bill처럼 CV가 작으면 평균 하나로 어느 정도 대표가 가능하다.
  - 재고 관리·수요 예측·예산 편성 모두 CV가 낮을수록 계획 신뢰도가 높다.

# Part 2 [왜도≈0, 첨도 매우 큰 분포 — 모양 추정과 근거]

왜도와 첨도의 역할부터 정리:
  - 왜도: 분포의 좌우 대칭성 (0 = 대칭)
  - 첨도: 꼬리의 두꺼운 정도 / 봉우리의 뾰족함
         (초과첨도 기준: 0 = 정규분포, 양수 = 더 뾰족+두꺼운 꼬리)

▶ 왜도 ≈ 0  →  분포가 좌우 대칭
  - 평균 ≈ 중앙값 ≈ 최빈값
  - 특정 방향으로 꼬리가 치우치지 않음

▶ 첨도 >> 0  →  정규분포보다 '뾰족+두꺼운 꼬리'
  - 중심(평균 근처)에 데이터가 매우 몰려 있음 — 봉우리가 날카로움
  - 동시에 양쪽 꼬리에 극단값이 정규분포보다 많이 존재 — '두꺼운 꼬리'
  - 이를 '렙토쿠르틱(leptokurtic)' 분포라 부름

▶ 그림으로 그린다면:
  - 중심이 뾰족하게 솟아 있는 대칭 종 모양
  - 정규분포보다 봉우리가 훨씬 높고 좁음
  - 대신 양쪽 꼬리가 정규분포보다 두껍게 퍼져 있음
  - 직관: "대부분은 중간에 있는데, 가끔 극단값이 터진다"

실제 사례:
  - 주식 일별 수익률: 평소엔 0% 근처에 몰리지만 폭락/폭등이 종종 발생
  - IQ 점수: 100 근처에 몰리지만 매우 낮거나 높은 극단 사례 존재
  - 금융 리스크: 정규분포로 가정하면 극단값 확률을 과소평가하는 이유

비즈니스 관점:
  - 단순히 '평균·표준편차'로만 요약하면 극단 이벤트 리스크를 놓침
  - 첨도가 높을수록 VaR(Value at Risk) 같은 꼬리 리스크 지표가 중요해짐 


# Part 3 [3번 주석 — 쿠폰 사용 수·비율 분포 판단]

▶ "사용 인원 수(정수)"는 이항분포

  근거:
  - 조건 4개 충족: 고정된 n(1000명), 성공/실패 두 결과,
    각 사람의 사용 확률 p=0.07 일정, 사람들 독립적
  - 결과가 "몇 명"이라는 정수 (0~1000)
  - 실측 평균 69.93 ≈ 이론 np = 70.0
  - 실측 분산 59.32 ≈ 이론 np(1-p) = 65.1

  포아송 근사 여부:
  - n=1000 크고 p=0.07 작아 포아송 근사 가능 (np=70 ≥ 30)
  - 단, 이항이 더 정확. n이 유한하고 p가 0에 충분히 작지 않을 때
    이항을 쓰는 게 원칙. 포아송은 n→∞, p→0 극한

  정규 근사 여부:
  - np=70≥5, n(1-p)=930≥5 → 정규 근사 가능
  - 실제로 왜도 0.21로 거의 대칭 → 정규분포와 유사한 모양

▶ "사용 비율(0.07 근처 연속값)"은 정규분포로 근사

  근거:
  - 비율 = 사용수/1000 → 연속적인 값
  - CLT에 의해 표본 비율의 분포는 정규분포에 수렴
    (np=70≥5, n(1-p)=930≥5 조건 충족)
  - 이론 SE = √(p(1-p)/n) = √(0.07×0.93/1000) = 0.0081
    실측 표준편차 0.0077과 거의 일치
  - 정밀한 구간 추정에는 베타분포가 더 적합하지만,
    n=1000이면 정규 근사도 충분히 정확

▶ 요약
  사용 수(횟수)  →  이항분포   (n=1000, p=0.07)
  사용 비율     →  정규분포 근사 (CLT, SE=0.0081)
