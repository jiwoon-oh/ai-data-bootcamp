## 모델 카드 v1 — 구매 전환 예측

- 데이터: UCI Online Shoppers (12,330 세션, 수치형 10개 열만 사용)
- 문제 유형: 분류
- 모델: 베이스라인(Dummy) → LogisticRegression
- 평가 지표 & 이유: Accuracy, 단, 클래스 비율이 불균형이므로 Precision/recall/F1-score모두 함께 봐야함
- 성능: 베이스라인 0.8451 → 내 모델 0.8796 / 학습 0.8839 vs 테스트 0.8796
- 과적합 진단: 학습 -테스트 격차가 0.0043(0.4%p)로 매우 작아 과적합 의심 X, 오히려 베이스라인 대비 개선폭(3.45%p)이 작아 과소적합쪽이 의심됨
- 한계 & 다음 단계: 범주형 8개 열을 사용하지 않았기 때문에 인코딩 후 추가하면 개선 가능성 있음, Revenue 불균형 미확인, confusion matrix로 다른 평가지표들도 확인해야함

## 모델 카드 v1 — 자전거 대여량 예측

- 데이터: UCI Bike Sharing (731일, 날씨 피처 4개)
- 문제 유형: 회귀
- 모델: 베이스라인(Dummy) → LinearRegression
- 평가 지표 & 이유: R², 평균만 찍는 것보다 얼마나 잘 설명하는가 를 직관적으로 보여주는 지표이다
- 성능: 베이스라인 -0.020 → 내 모델 0.499 / 학습 0.450 vs 테스트 0.499
- 과적합 진단: 과적합 신호 거의 없음, 학습/테스트 성능이 비슷한 수준
- 한계 & 다음 단계: 날씨 피처 4개만 사용 → 계절, 요일, 공휴일 등 시간 피처 추가 시 개선 여지 큼 { 다음 세션? }
  - temp와 atemp는 상관관계가 매우 높을 가능성 → VIF로 다중공선성 확인 필요
  - 선형 관계만 가정 → 비선형 모델(트리 계열) 비교해볼 여지
