## 2. 검정 선택 근거  ← 오늘의 핵심
| 질문 | 데이터 특성 | 선택한 검정 | 이유 |
| --- | --- | --- | --- |
| 등급 × 생존 | 둘 다 범주형 | 카이제곱 독립성 | 빈도 비교 |
| 흡연 × 폐암 | 2×2 범주형 | 카이제곱 + 오즈비 | 연관·강도 |
| 그룹 × 연락 | 2×2 범주형(무작위 배정) | 카이제곱 + V·OR | A/B 구조 |
| 등급별 요금 | 연속형·우편향 | Kruskal-Wallis | 정규성 위배 |
| 같은 기업 87/88 불량률 | 짝지어진 연속형·비정규 | Wilcoxon 부호순위 | 대응 + 정규성 위배 |
