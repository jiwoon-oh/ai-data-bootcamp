# H2 검증 — EDA 파이프라인

**H2**: 골목상권의 순감소 위험이 높은 업종의 경우, 점포 규모와 유동인구를 맞추면 타 업종과 순감소 격차가 줄어들 것이다.

---

## 실행 순서

VSCode에서 `src/` 안의 노트북을 순서대로 엽니다.

```
src/step1_load.ipynb       적재 + 스키마 통일
src/step2_merge.ipynb      결합 + 조인 검증
src/step3_label.ipynb      라벨 + 필터 + 로그 변환
src/step4_eda_basic.ipynb  기초 EDA
src/step5_eda_h2.ipynb     H2 핵심 EDA
```

`data/raw/` 에 CSV를 넣으면 됩니다. 각 노트북 첫 셀이 `config.py` 를 찾아 프로젝트 루트로 이동하므로 **어느 폴더에서 열든 동작**합니다. 각 단계는 독립 실행 가능하며 이전 단계의 `.pkl` 을 읽습니다.

필요 패키지: `pandas numpy matplotlib scipy ipykernel`

### 미사용 파일

`점포-자치구`, `추정매출-자치구`, `길단위인구-자치구`, `소비-자치구`, `상권변화지표-자치구` — 모두 자치구 단위라 상권 간 변별력이 없습니다. 같은 구의 모든 상권이 동일 값을 가지므로 매칭 공변량으로 쓸 수 없습니다.

## 단계별 처리 내용

### step1_load.ipynb — 적재 및 스키마 통일
점포 파일의 컬럼명이 연도별로 다릅니다.

| | 2023·2024 | 2025~ |
|---|---|---|
| 점포 총수 | `점포_수` | `전체_점포_수` |
| 부가 | `유사_업종_점포_수` | `일반_점포_수` |

공통 의미 컬럼만 남기고 `점포_수` 로 통일합니다. `유사_업종_점포_수` 와 `일반_점포_수` 는 한쪽에만 있으므로 폐기합니다.

매출은 2025년 파일과 `_.csv` 가 20251~20254 구간에서 중복됩니다. `drop_duplicates(keep="last")` 로 제거합니다.

### step2_merge.ipynb — 결합
좌결합 후 행 수가 변하면 즉시 예외를 던집니다. 키 중복으로 행이 증식하는 것이 이 단계 최대 위험입니다.

### step3_label.ipynb — 라벨
```
y(t) = 1 if (개업_점포_수(t+1) − 폐업_점포_수(t+1)) < 0 else 0
```
`shift(-1)` 은 반드시 (상권, 업종) 그룹 내에서 분기 정렬 후 수행합니다. 분기가 연속하지 않으면 라벨을 만들지 않습니다.

필터: 라벨 존재 → 점포 5개 이상 → 유동인구 존재 → 면적 유효

### step4_eda_basic.ipynb — 기초 EDA
상권유형별·자치구별 순감소율, 분포 확인, 공변량 상관.

### step5_eda_h2.ipynb — H2 핵심 EDA
업종별 순감소율로 처리군을 데이터가 정하게 하고, 단순 격차 → 규모 교란 진단 → SMD → 공통지지영역 → 카이제곱 순으로 확인합니다.
