# H2 검증 — EDA 파이프라인

**H2**: 골목상권의 순감소 위험이 높은 업종의 경우, 점포 규모와 유동인구를 맞추면 타 업종과 순감소 격차가 줄어들 것이다.

**보조질문 2**: 매출·유동인구·점포 밀도 등 어떤 특성이 다음 분기 순감소 전환과 관련되는가?

> **두 질문의 순서** — 보조질문 2가 논리적으로 앞서 보이지만 **실행은 H2(PSM)를 먼저** 합니다. 결과변수와의 관계를 보고 공변량을 고른 뒤 매칭하면 "격차가 줄어드는 것"이 설계상 당연해지기 때문입니다. 지금은 공변량 선택을 H2 문장(점포 규모·유동인구)이 사전 지정하고 있고, 보조질문 2는 매칭 표본 위에서 돌려 이중강건 추정을 겸합니다. 보고서 서술 순서는 반대(보조질문 2 → H2)로 배치해도 사후 짜맞추기가 아닙니다.

## 알아두어야 할 원본 데이터의 함정

### ① `점포_수` 는 총 점포수가 아니다

원본 두 세대에서 다음 항등식이 **100%** 성립합니다.

```
2023·2024 :  유사_업종_점포_수 = 점포_수     + 프랜차이즈_점포_수
2025~     :  전체_점포_수     = 일반_점포_수 + 프랜차이즈_점포_수
```

| 의미 | 2023·2024 | 2025~ |
|---|---|---|
| **총 점포수** | `유사_업종_점포_수` | `전체_점포_수` |
| 비프랜차이즈 | `점포_수` | `일반_점포_수` |

구파일의 `점포_수` 는 **비프랜차이즈 점포수**입니다. 2025년 개편에서 `일반_점포_수` 로 개명되고, 총수에 `전체_점포_수` 라는 이름이 새로 붙었습니다.

두 세대를 이름만 보고 이어붙이면 2024Q4 → 2025Q1 에서 골목상권 외식업 평균 점포수가 **5.22 → 6.16 (+18%)** 로 점프합니다. 실제로 일어난 일이 아니라 정의가 바뀐 것입니다. 게다가 과소 정도가 업종마다 다릅니다 — 치킨 64%, 패스트푸드 50%, 한식 10% — 그래서 매칭 공변량 자체가 왜곡됩니다.

STEP 1 이 매 실행마다 이 항등식과 분기별 연속성을 재검증합니다.

### ② 매출 결측 45% 는 업종 커버리지 문제가 아니다

매출 파일에는 10개 외식업이 **모두** 들어 있습니다. 결측의 진짜 원인은 **칸 단위 비식별 처리**입니다.

| 전체_점포_수 | 0 | 1 | 2 | 3-4 | 5-9 | 10-19 | 20-49 | 50+ |
|---|---|---|---|---|---|---|---|---|
| 매출 결측률 | 100% | 100% | 100% | 33.5% | 13.5% | 3.3% | 1.3% | 0.2% |

점포가 2개 이하인 칸은 매출을 공개하면 개별 점포 매출이 드러나므로 값을 비웁니다.

**따라서 STEP 3 이 점포 5개 미만을 걸러낸 뒤에는 매출이 92.9% (골목상권 90.9%) 관측됩니다.** 매출은 보조질문 2 에서 정상적으로 쓸 수 있습니다.

조인 자체는 검증했습니다 — 키 자료형 일치, 매출 87,558행이 **전부** 점포 행에 붙었고 고아 행 0건. 짝을 못 찾은 점포 행 72,794개의 점포수 중앙값은 2개입니다. 결측은 조인 실패가 아니라 원본 데이터의 성질입니다.

### ③ 매출을 매칭 공변량에 넣지 않는 이유

결측 때문만이 아닙니다. 두 가지가 겹칩니다.

**과잉통제** — 매출은 업종의 **결과**입니다. 한식집과 카페는 사업 모형이 달라 매출 수준이 다르고, 그 차이가 폐업 위험으로 이어지는 것은 업종 효과의 일부입니다. 매출을 맞춰버리면 "매출이 같은 한식과 카페 중 누가 더 닫나"를 묻게 되어 업종이 작동하는 경로 하나를 막습니다. 반면 유동인구·면적·집객시설은 업종 선택이 만들어낸 값이 아니라 상권의 속성이므로 통제 대상이 맞습니다.

**비대칭 결측** — 분석 표본에서도 관측률이 한식 98.8% vs 양식 79.7% 로 벌어집니다. 공변량에 넣으면 대조군만 선택적으로 빠집니다.

→ PSM 주 분석에서는 제외하고, 매출이 관측된 부분표본 강건성 분석과 보조질문 2(STEP 7)에서 씁니다.

## 단계별 처리 내용

### step1_load.ipynb — 적재 · 스키마 통일 · 범위 필터 · 완전성 검증

1. **원본 보존** — `_raw` 로 적재 후 `.copy()` 로 작업
2. **스키마 통일** — 구파일을 신파일 이름 기준으로 리네임하고 항등식·분기 연속성으로 검증
3. **분모 먼저** — `상권_전체점포`(100개 업종 합), `상권_외식점포` 를 **업종 필터 전에** 계산. 순서를 바꾸면 영영 못 만듭니다
4. **범위 필터** — 13분기 · 10업종. 여기서 점포 테이블이 995,377 → 160,352행 으로 줄어듭니다
5. **완전성 검증** — 교차표(업종별 상권 커버리지)와 분기 연속성 진단
6. 매출 중복 제거 (2025 파일과 무연도 파일이 20251~20254 구간에서 완전 중복)

파생 컬럼: `외식_비중`, `프랜차이즈_비율`

**커버리지가 업종마다 크게 다릅니다** — 골목상권 1,084개 기준 한식 96.2%, 커피 94.3% … 일식 55.4%. 대조군으로 쓸 수 있는 상권 풀이 업종마다 다르다는 뜻이고, PSM 매칭률에 직접 영향을 줍니다.

### step2_merge.ipynb — 결합

행 증식이 이 단계 최대 위험입니다. 오른쪽 테이블 키가 중복이면 좌결합만으로 행이 늘어나고, 어떤 상권-분기가 두 번 들어 있으면 그 상권의 **모든 업종 행이 두 배**가 됩니다.

방어를 두 겹으로 둡니다 — 결합 **전** 오른쪽 키 유일성 직접 확인, 결합 **시** `validate="many_to_one"`, 결합 **후** 행 수 비교.

`상권유형` 은 영역-상권에서 받고, 점포 테이블의 `상권_구분_코드_명` 과 일치하는지 교차 확인한 뒤 중복 컬럼을 버립니다.

결측 진단 결과: 유동인구 0.0% / 집객시설 2.3% / 지하철역 85.0%(미사용) / 매출 45.4%(위 ② 참조).

### step3_label.ipynb — 라벨

```
y(t) = 1 if (개업_점포_수(t+1) − 폐업_점포_수(t+1)) < 0 else 0
```

`shift(-1)` 은 반드시 (상권, 업종) 그룹 내에서 분기 정렬 후 수행합니다. 분기가 연속하지 않으면 라벨을 만들지 않습니다.

필터: 라벨 존재 → `전체_점포_수` ≥ 5 → 유동인구 존재 → 면적 유효

**20261 은 라벨 공급용입니다.** 20254 의 `y` 를 만들려면 20261 의 개업·폐업이 필요합니다. 20261 행 자체는 다음 분기가 없어 라벨을 못 만들고 여기서 탈락합니다 → 학습 구간 20231~20254, 12분기.

#### 점포수 기준 변경의 영향

5개 이상 필터가 `일반_점포_수`(비프랜차이즈) → `전체_점포_수`(총수) 기준으로 바뀌면서 표본이 **55,795 → 67,475행 (+20.9%)** 로 늘었습니다. 유입이 업종별로 극심하게 편중돼 있습니다.

| 업종 | 이전 표본 | 신규 유입 | 증가율 |
|---|---|---|---|
| 치킨전문점 | 854 | 3,332 | **+390%** |
| 패스트푸드점 | 1,687 | 2,214 | +131% |
| 제과점 | 2,988 | 1,145 | +38% |
| … | | | |
| 한식음식점 | 15,335 | 342 | **+2%** |

프랜차이즈 비중이 높은 업종일수록 이전에 심하게 과소 집계되고 있었다는 뜻입니다. 처리군(한식)은 2%만 늘고 대조군은 크게 늘었으므로 **이전 PSM 결과와 직접 비교할 수 없습니다.**

신규 유입 칸의 순감소율은 **16.9%** 로 기존 표본(27.3%)보다 뚜렷이 낮습니다. 전체 양성률이 내려가고 업종별 순위도 바뀔 수 있습니다.

#### 점포 밀도

`점포밀도 = 전체_점포_수 / 영역_면적` 을 만들지만 **매칭 공변량으로 추가하지 않습니다.** `log(밀도) = log(점포수) − log(면적)` 이라 이미 매칭 중인 두 변수의 선형결합이고, 별도로 넣으면 완전 공선성이 됩니다. 해석·기술통계용입니다.

### step4_eda_basic.ipynb — 기초 EDA

결론을 내는 단계가 아니라 **어디를 파야 하는지 정하는** 단계입니다. 각 절이 이후 질문의 예고편입니다.

| 절 | 보는 것 | 예고하는 질문 |
|---|---|---|
| 4-2 | 업종별 순감소율, 규모↔위험 상관 | **H2** 처리군 후보 |
| 4-3 | 자치구별 순감소율, 자치구별 최고 위험 업종 | **핵심 질문** |
| 4-4 | 상권유형 × 업종 | 기술 통계 (H1 은 직접 검증하지 않음) |
| 4-5 | 왜도와 로그 변환 | 매칭 안정성 |
| 4-6 | 공변량 상관 · VIF | 성향점수 모형 |
| 4-7 | 특성별 5분위 순감소율 | **보조질문 2** |

**주의할 점**

- **관광특구는 상권이 6개뿐입니다.** 칸 수는 696개로 보이지만 독립 상권은 6개라, 여기서 나오는 수치로 결론을 내지 않습니다
- 자치구 × 업종으로 쪼개면 칸이 얇아집니다. 248개 조합 중 140개가 100칸 미만이라 순위에서 제외합니다
- 5분위 프로파일은 동점이 많은 변수(`프랜차이즈_비율` 등)에서 `qcut` 이 구간을 못 나누므로 **순위 기준 5등분**을 씁니다

**VIF** — `log_면적`(2.65)과 `log_집객시설`(2.25)이 가장 높지만 10에 한참 못 미칩니다. 성향점수는 예측만 하므로 그대로 씁니다.

### step5_eda_h2.ipynb — H2 핵심 EDA

**매칭이 필요한지, 매칭이 가능한지**를 매칭 전에 확인합니다. 업종별 순감소율로 처리군을 데이터가 정하게 하고, 처리군 선택 안정성 → 단순 격차 → 규모 교란 진단 → SMD → 공통지지영역 → 단면 카이제곱 순으로 봅니다.

#### 처리군 선택 안정성 (5-2)

1위(한식 25.3%)와 2위(커피-음료 24.4%) 격차가 **0.9%p** 로 좁습니다. 처리군을 데이터가 정하는 설계이므로 그 결정이 흔들림에 견디는지 확인합니다.

- **상권 단위 클러스터 부트스트랩 1,000회** — 한식이 1위인 비율 **78.3%**, 상위 2위 안에 드는 비율 95.6%
- **분기별 1위** — 12분기 중 한식이 1위인 분기는 3개뿐. 단일 분기 순위는 표본이 얇아(패스트푸드 분기당 120칸) 크게 흔들립니다

→ ATT 를 "한식음식점의 효과"로 단정하기보다 **"순감소율 상위권 업종의 효과"** 로 범위를 두고 보고하는 편이 안전합니다.

#### 규모 교란 진단 (5-4)

**단순 비교와 구간 내 비교의 부호가 정반대입니다.**

| 점포수 5분위 | 대조군 | 한식 | 격차 |
|---|---|---|---|
| Q1 (작음) | 15.3% | 10.7% | −4.7%p |
| Q2 | 18.4% | 14.2% | −4.2%p |
| Q3 | 22.6% | 16.2% | −6.4%p |
| Q4 | 30.4% | 24.2% | −6.2%p |
| Q5 (큼) | 38.9% | 33.8% | −5.1%p |
| **전체(단순)** | 22.9% | 25.3% | **+2.4%p** |

다섯 구간 **전부** 한식이 낮은데 합치면 한식이 높습니다. 전형적인 심슨의 역설이고, 원인은 한식이 Q5 에 몰려 있기 때문입니다(한식 4,409칸 vs 대조 2,521칸). PSM 이 정밀하게 하려는 일을 거친 구간 나누기로 미리 본 셈입니다.

#### 매칭 전 SMD

| 공변량 | SMD | 판정 |
|---|---|---|
| `log_점포수` | +0.999 | 심각한 불균형 |
| `log_면적` | −0.473 | 심각한 불균형 |
| `log_집객시설` | −0.461 | 심각한 불균형 |
| `log_유동인구` | −0.447 | 심각한 불균형 |

공통지지영역은 4개 공변량 모두 99.9~100% — 매칭에서 버려지는 관측치가 거의 없을 것으로 예상됩니다.

#### 왜 단일 분기로 검정하는가 (5-7)

전 분기를 풀링하면 같은 상권이 최대 12번 반복 관측되어 표본 크기가 인위적으로 부풀려지고, 미미한 차이도 "유의하다"고 나옵니다. 가장 최근 분기(20254, n=2,772)만 잘라 검정하면 p = 0.034 로 유의하지만 Cramér's V = 0.040 으로 매우 작습니다 — **통계적 유의성과 실질적 크기는 다르다**는 사례입니다.

### step6_psm.ipynb — 성향점수매칭

성향점수(4개 공변량 + 분기 더미) → 공통지지 트리밍 → 분기 고정 1:1 최근접 매칭(캘리퍼 0.2·SD, 비복원) → **매칭 후 SMD 균형 검증** → ATT + McNemar + 상권 단위 클러스터 부트스트랩 → 매칭 실패 처리군 진단 → 민감도(캘리퍼·복원·시드).

균형 검증(모든 공변량 |SMD| < 0.1)을 통과하지 못하면 ATT를 해석하지 않습니다. 처리군 매칭률과 매칭 실패 칸의 순감소율을 함께 보고해, "격차가 줄었다"가 "격차를 만들던 관측치를 버렸다"가 아닌지 확인합니다.

#### 매칭 전 SMD 가 전부 "심각한 불균형"이어도 진행하는 이유

매칭 전 SMD 는 통과해야 할 관문이 아니라 **문제의 크기를 재는 눈금**입니다. 작았다면 두 집단이 이미 비슷하다는 뜻이라 PSM 자체가 불필요합니다. **관문은 매칭 _후_ SMD** 이고, 그것이 6-4 입니다.

#### 결과

| | 값 |
|---|---|
| 매칭쌍 | 7,042쌍 (처리군 매칭률 70.7%) |
| 매칭 후 최대 SMD | 0.037 — 4개 공변량 전부 균형 통과 |
| 매칭 전 단순 격차 | **+2.4%p** |
| **ATT** | **−5.8%p** (클러스터 부트스트랩 95% CI −7.2 ~ −4.2%p) |
| McNemar | b=1,142 / c=1,547, p = 5.9e−15 |

**격차가 줄어든 게 아니라 부호가 역전됐습니다.** 단순 격차 +2.4%p 는 규모 교란의 산물이었고, 조건을 맞추면 한식이 오히려 5.8%p 낮습니다. H2 가 예측한 "축소"보다 강한 결과입니다.

민감도 10개 설정 전부 부호가 일관됩니다 (−4.4 ~ −6.0%p). 자치구까지 고정해도 −5.8%p(6,118쌍), 매출을 공변량에 넣어도 −4.4%p(5,311쌍).

**함께 보고할 것** — 처리군 매칭률 70.7%. 짝을 못 찾은 2,913칸은 점포수가 큰(log 3.24 vs 2.60) 대형 한식 밀집 칸이고 순감소율이 30.6% 로 높습니다. ATT 는 **비교 가능한 규모 구간에 한정된** 효과입니다. 처리군 선택 부트스트랩 1위 비율도 78.3% 이므로 "한식음식점의 효과"보다 **"순감소율 상위권 업종의 효과"** 로 범위를 두는 편이 안전합니다.

## 이후 단계 — 인과에서 예측으로

STEP 1~6 은 **인과 파트**(H2)입니다. STEP 7~9 는 **설명과 예측 파트**로, 핵심 질문에 실제로 답하는 구간입니다.

### 시간 분할 — 이 프로젝트의 뼈대

한 행은 `(상권, 업종, 피처분기 t)` 이고 라벨은 `y(t) = [순감소 in t+1]` 입니다. **라벨이 한 분기 앞을 보므로 피처분기와 타깃분기가 다릅니다.** 여기를 헷갈리면 누수가 납니다.

| 용도 | 피처 분기 t | 타깃 분기 t+1 | 라벨 | 행 수(전체 패널) |
|---|---|---|---|---|
| **학습** | 20231 ~ 20253 | 20232 ~ 20254 | 있음 | 61,996 |
| **검증** | 20254 | **20261** | 있음 | 5,479 |
| **예측** | **20261** | **20262** | 없음 | 5,428 |

- 검증 세트는 20261 의 실제 개업·폐업으로 채점하므로 **진짜 미래 예측을 흉내낸 평가**입니다
- 예측 세트(피처 20261)는 라벨이 없어 학습 패널에서 탈락하므로, STEP 3 이 **같은 필터·같은 변환**을 적용해 `03_score.pkl` 로 따로 저장합니다
- 학습에 20254 행을 넣으면 20261 결과를 미리 보게 되므로 **반드시 제외**합니다. `config.TRAIN_QUARTERS` 가 이미 제외하고 있으니 STEP 8·9 는 그 상수를 씁니다 (STEP 3 과 STEP 7 이 `assert` 로 재확인)

검증 분기가 하나뿐이라 얇습니다. 그래서 최종 홀드아웃(20254→20261) 과 별도로 **롤링 오리진 검증**(학습 종료 분기를 20249, 20251, 20252, 20253 으로 밀며 반복)을 함께 돌려 성능의 분기 간 변동을 봅니다.

### step7_explain.ipynb — 보조질문 2 (설명) · 완료

두 가지를 합니다. 표본이 다르니 헷갈리지 마세요.

| | 표본 | 목적 |
|---|---|---|
| 7-1 이중강건 | 매칭 표본 | ATT 재확인 |
| 7-3~7-6 설명 모형 | 골목상권 · **학습 분기만** | 보조질문 2 본론 |

설명 모형이 `TRAIN_QUARTERS` 만 쓰는 이유 — 여기서 얻은 변수 선택·형태 판단이 STEP 8 로 넘어가는데, 검증 분기(20254)를 보고 정한 것이면 검증이 무의미해집니다.

#### 세 방법이 같은 결론에 도달했습니다

| | 격차 (한식 − 대조) |
|---|---|
| 단순 비교 (STEP 5) | +2.4%p |
| 매칭 ATT (STEP 6) | −5.8%p |
| **이중강건 ATT (STEP 7)** | **−6.1%p** |

매칭 ATT 와 이중강건 ATT 차이가 0.4%p 밖에 안 됩니다 — 매칭이 이미 조건을 잘 맞췄다는 뜻입니다.

설명 모형에서도 같습니다. 업종 더미(기준 한식) **9개 전부 양(+)이고 전부 p < 0.001** — 공변량을 통제하면 한식이 10개 업종 중 가장 안전합니다.

#### 보조질문 2 답변

| 순위 | 변수 | AME | 방향 |
|---|---|---|---|
| 1 | `log_점포수` | **+14.3%p** | 점포가 많을수록 위험 |
| 2 | 업종: 패스트푸드 | +13.9%p | 한식 대비 |
| 3 | `외식_비중` | **−13.8%p** | 상권 내 외식 비중이 높을수록 안전 |
| 4~11 | 업종 더미 | +5.9 ~ +10.6%p | 전부 한식보다 위험 |
| — | `log_유동인구` | +0.7%p (p=0.078) | **유의하지 않음** |
| — | 프랜차이즈 구간 | 전부 유의하지 않음 | 업종을 통제하면 사라짐 |

**AME**(평균한계효과)는 계수를 확률 척도로 옮긴 값이라 "%p 변화"로 바로 읽힙니다. 표준오차는 상권 단위 군집으로 계산합니다(같은 상권이 최대 11분기 반복 관측).

두 가지가 눈에 띕니다.

- **유동인구는 규모를 통제하면 거의 무의미해집니다.** H2 가 명시한 변수인데, 단독으로는 위험을 설명하지 못하고 점포수와 함께 봐야 의미가 생깁니다
- **프랜차이즈 비율의 비단조 패턴(STEP 4)은 업종 구성의 착시였습니다.** 업종 더미를 넣으면 세 구간 모두 유의성이 사라집니다

매출(`log_점포당매출`)은 관측 부분표본(90.9%)에서 −2.2%p, p < 0.001 로 유의하지만 pseudo R² 를 0.035 → 0.040 으로 올릴 뿐입니다. 규모 변수가 이미 그 정보를 대부분 담고 있습니다.

#### 대조군이 실제로 무엇인가 (7-2)

매칭이 고른 대조군은 균등하지 않습니다.

| 업종 | 매칭 대조군 비중 | 골목 풀 비중 | 배율 |
|---|---|---|---|
| 커피-음료 | 52.7% | 31.4% | **1.68×** |
| 호프-간이주점 | 21.4% | 18.6% | 1.15× |
| 치킨전문점 | 2.0% | 7.8% | 0.25× |
| 패스트푸드점 | 1.4% | 5.8% | 0.24× |

규모·유동인구를 맞추다 보니 점포수가 큰 커피·호프가 과대표집됐습니다. **ATT 를 "한식 vs 기타 외식업 전체"라고 뭉뚱그리면 안 되고, "한식 vs 커피·호프 중심의 대조군"으로 적어야 정확합니다.**

### step8_predict.ipynb — 예측 모델 + 시간 분할 검증 · 완료

**핵심 질문은 예측 질문입니다.** step7 이 "왜"를 답했다면 step8 은 "무엇을"을 답할 준비를 합니다.

피처는 `config.build_features` / `config.design_matrix` 로 만듭니다. **step9 가 같은 함수를 호출하므로 학습과 예측이 어긋날 수 없습니다**(train/serve skew 방지).

**분기 더미를 넣지 않습니다.** step6·7 의 성향점수·설명 모형에는 넣었지만 그건 설명이라 학습 분기 안에서만 쓰면 됐습니다. 예측 대상 20261 은 학습에 없는 분기라 더미를 만들 수 없고, 만들어도 전부 0 이 됩니다. 미래 분기의 계절 효과는 알 수 없다는 게 정직한 태도입니다.

새로 넣은 것은 **현재 모멘텀**(`개업률`, `폐업률`, `순증감률`, `순감소_현재`) — 피처 분기 시점 값이라 누수가 아닙니다.

#### 성능

| 모형 | AUC | PR-AUC | Brier |
|---|---|---|---|
| A 항상 평균 | 0.500 | 0.260 | 0.192 |
| B 직전분기 상태 | 0.532 | 0.274 | 0.218 |
| C 업종 평균 | 0.554 | 0.291 | 0.191 |
| D 로지스틱 | **0.670** | 0.407 | 0.180 |
| **E 부스팅** (선택) | 0.668 | **0.417** | **0.179** |
| F 랜덤포레스트 | 0.663 | 0.413 | 0.180 |

PR-AUC 무작위 기준선은 검증 양성률 0.260 이므로 **1.61배**입니다. 롤링 오리진 6회에서 AUC 0.666 ± 0.010 으로 분기 간 변동이 거의 없습니다.

확률 보정도 양호합니다 — 10분위 각 구간에서 평균 예측과 실제 발생률의 최대 오차 0.053.

#### ★ 어느 단위까지 믿을 수 있나 (8-7)

step9 는 자치구 × 업종 표를 만듭니다. 그런데 **비교 대상인 "실제 값"부터 믿을 만한지** 먼저 재야 합니다. 같은 칸의 관측치를 무작위로 반씩 나눠 각 절반의 순위가 서로 얼마나 일치하는지 보는 **반분 신뢰도**를 씁니다. 같은 데이터를 쪼갠 것뿐이므로 이 값이 낮으면 그 단위의 관측값은 사실상 잡음입니다.

**단일 분기(20254, 골목상권 n=2,772)**

| 단위 | 칸수 | 칸당 중앙 표본 | 반분 신뢰도 |
|---|---|---|---|
| 업종 | 10 | 138 | +0.212 |
| 자치구 | 25 | 119 | +0.086 |
| 자치구×업종 | 240 | **7** | **+0.035** |

**단일 분기로는 어떤 단위에서도 순위를 평가할 수 없습니다.** 자치구×업종은 칸당 7행뿐이라 "실제 값"조차 재보면 순위가 뒤바뀝니다.

**out-of-fold 6분기 풀링** (각 분기를 그 이전 데이터로만 예측한 값을 모음, 골목상권 16,913행)

| 단위 | 칸수 | 칸당 중앙 표본 | 예측↔실제 순위상관 | 목표 반분 신뢰도 |

순위상관이 목표 자체의 반분 신뢰도보다 높습니다 — **모형이 잡음 낀 관측값보다 오히려 그 칸의 참값에 가깝다**는 뜻입니다.

자치구별 최고 위험 업종 top-1 적중률은 **45.0%**(무작위 24.1%)입니다. 무작위의 2배에 가깝지만 절반은 틀립니다. → **step9 는 "1위 업종"을 단정하지 말고 확률과 표본 수를 함께 실은 순위표로 제시합니다.**

`log_점포수` 가 압도적입니다 — 섞으면 AUC 가 0.162 떨어집니다. 나머지는 전부 0.006 이하로, `log_점포당매출`·`순증감률`·`호프-간이주점` 순입니다. **점포 규모 하나가 예측력의 대부분을 설명합니다.**

#### 9-1 반사실 시뮬레이션 — H2 를 예측 모형으로 재검증

STEP 6 의 PSM 이 **짝을 지어** 조건을 맞췄다면, 여기서는 STEP 8 모형으로 **값을 강제로 바꿔** 같은 실험을 합니다. 특정 변수만 전부 중앙값으로 치환하고 예측 격차를 다시 계산합니다.

| 무엇을 고정했나 | 예측 격차 | 95% CI |
|---|---|---|
| 아무것도 안 함 | +3.07%p | [+2.5, +3.6] |
| **점포 규모만** | **−5.74%p** | [−6.0, −5.5] |
| 유동인구만 | +3.57%p | [+3.0, +4.1] |
| 면적만 | +3.20%p | [+2.6, +3.7] |
| 점포당매출만 | +6.09%p | [+5.5, +6.6] |
| 규모 + 유동인구 (H2 명시) | −5.49%p | [−5.7, −5.3] |
| 공변량 4개 전부 | −5.79%p | [−6.0, −5.6] |

**점포 규모 하나만 맞춰도 PSM 전체(−5.76%p)와 같은 결과가 나옵니다.** 유동인구를 맞추면 격차가 오히려 조금 벌어집니다.

용량-반응도 확인했습니다 — 점포수를 5개부터 27개까지 강제해도 **모든 구간에서 한식이 낮습니다**(−1.4 ~ −6.5%p).

#### 9-2 ★ "규모가 클수록 위험"의 정체

STEP 7·8 이 공통으로 지목한 1위 변수가 `log_점포수` 인데, 이걸 "점포가 많으면 폐업 위험이 높다"로 읽으면 **틀립니다.**

라벨이 `y(t) = [개업(t+1) − 폐업(t+1) < 0]` 이라, 점포가 적은 칸은 다음 분기에 **아무 일도 안 일어날 확률**이 높고 그러면 순증감 = 0 이라 `y = 0` 이 됩니다.

| 전체 점포 수 | 다음 분기 사건 발생률 | 순감소율(전체) | **순감소율(사건 있는 칸만)** |
|---|---|---|---|
| 5 | 29.1% | 14.6% | **50.1%** |
| 8-10 | 45.4% | 21.3% | 47.0% |
| 16-25 | 73.9% | 31.9% | 43.2% |
| 51+ | 97.9% | 37.7% | **38.5%** |

**사건이 있었던 칸만 보면 규모가 클수록 순감소율이 오히려 낮아집니다.** "규모 → 위험"의 정체는 "규모 → 사건 발생 확률"이었습니다.

이것이 H2 를 무너뜨리지는 않습니다 — 매칭은 규모를 맞춘 상태에서 비교했으므로 두 집단이 같은 산술적 기저를 공유합니다. 영향받는 것은 **보조질문 2 의 해석**입니다.

#### 9-3 유동인구는 왜 무관하게 나왔나

세 가지를 구분해야 합니다.

| 모형 | 유동인구 계수 | p값 | AME |
|---|---|---|---|
| ① 유동인구만 | +0.222 | 3e−25 | +3.97%p |
| ② + 면적·집객시설 | +0.149 | 5e−08 | +2.66%p |
| ③ + 점포수까지 | +0.041 | 0.077 | +0.72%p |

**점포수를 넣는 순간 사라집니다.** 유동인구가 무관한 게 아니라 **점포수를 통해** 작동합니다(매개). 점포수를 통제하는 것은 그 경로를 막는 과잉통제입니다.

그리고 구조적 한계가 하나 더 있습니다 — 유동인구는 분산의 **99.0%가 상권 간**이고, **같은 상권-분기 안에서 10개 업종이 전부 같은 값**을 받습니다. 같은 상권에서 왜 한식은 줄고 커피는 안 줄었는지를 원리적으로 설명할 수 없습니다.

| | 정체 | 성격 |
|---|---|---|
| ① | 점포수 통제가 매개 경로를 차단 | **모형 설계** (과잉통제) |
| ② | 상권 단위 값이라 업종 간 변별력 0 | **데이터의 구조적 한계** |
| ③ | 시간대·연령대별 유동인구 미사용 | **데이터 활용의 한계** — 고칠 수 있음 |

보고 시에는 "유동인구가 폐업과 무관하다"가 아니라 **"점포 규모를 통제하면 유동인구의 추가 설명력이 없다"** 로 적어야 정확합니다.
