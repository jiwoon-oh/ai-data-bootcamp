## 1. Executive Summary (BLUF)

**한 줄 결론 — "한식음식점이 위험하다"는 건 착시다. 위험한 건 업종이 아니라 규모이고, 그마저도 우리가 쓰던 지표가 만든 산술이다.**

| | 값 | 의미 |
|---|---|---|
| 단순 비교 | 한식 순감소율 **25.3%** vs 타 업종 22.9% (**+2.4%p**) | 한식이 더 위험해 보임 |
| 그런데 그 격차의 정체는 | 순열검정 **p=0.344**, 88%가 선택 효과 | **애초에 유의하지도 않았음** |
| 규모·유동인구를 맞춘 뒤 | **ATT −5.77%p** (95% CI −7.2 ~ −4.2, McNemar p<0.001) | **부호가 뒤집힘** |
| 단, 그 효과는 균질하지 않음 | 점포 6개 −13.0%p … 점포 39개 **+2.4%p** (Woolf p<0.0001) | **규모에 따라 달라짐 — 아래 참조** |
| 검증 4종 | 매칭 −5.77 / 이중강건 −6.15 / 반사실 −5.79 / 대안라벨 −8.73 (%p) | 방법을 바꿔도 같은 결론 |
| 역전을 만든 범인 | **점포 규모 단독** (규모만 고정 −5.74%p, 유동인구만 고정 **+3.57%p**) | 유동인구는 기여 0 |

**H2 판정: 부분 지지(주의).** H2 는 "격차가 **줄어들** 것"을 예측했는데, 실제로는 **뒤집혔습니다**(|격차| 2.4%p → 5.8%p). 교란은 확인됐지만 방향이 예측과 다르므로 "지지"가 아니라 "부분 지지"로 적습니다.

**⚠️ 그리고 −5.77%p 를 단독으로 인용하면 안 됩니다.** 이 값은 규모가 다른 층들의 평균이고, 층별로 나눠 보면 **점포 6개 칸에서 −13.0%p, 점포 39개 칸에서 +2.4%p** 로 방향까지 바뀝니다(Woolf 동질성 검정 p<0.0001). 정확한 문장은 **"작은 칸일수록 한식이 안전하고, 점포 20개를 넘으면 그 이점이 사라진다"** 입니다 — §4-B 참조.

**보조질문 2 답 — 다음 분기 순감소와 관련된 특성은 사실상 점포 규모 하나입니다.**
점포수 1 로그 단위 증가 = 순감소 확률 **+14.3%p** (p<10⁻¹⁶⁰). 유동인구는 **+0.7%p, p=0.078 로 무의미**했고, 그 이유까지 두 겹으로 밝혀냈습니다(§4-D).

**실무용 산출물:** 2026Q2 골목상권 2,737칸 폐업 건수 예측. 폐업률 1위 **패스트푸드점 5.45%**, 최저 호프-간이주점 3.99%. 순감소 기준 1위였던 한식은 폐업률로는 **9위**입니다.

**도입 근거:** 서울시가 현재 쓰는 공식 상권변화지표는 Lift **0.937 — 무작위보다 못합니다**. 우리 모형은 상위 50칸 정밀도 **0.760**(점포수 규칙 0.380)이고, 두 목록은 **6%만 겹칩니다**.

## 2. 비즈니스 문제 정의

**누가 이 답을 쓰는가:** 자치구 소상공인 지원 담당자, 상권 컨설팅 배정 담당자, 예비 창업자 상담 창구.

**현재의 의사결정 방식:** 서울시 상권분석서비스의 **순감소(개업 < 폐업)** 지표로 위험 업종을 고르고, 그 업종에 컨설팅·자금을 우선 배정합니다.

**문제:** 이 방식이 정말 위험한 곳을 고르고 있는지 아무도 검증한 적이 없습니다. 순감소율 1위는 매 분기 한식음식점인데, 한식은 골목상권에서 점포가 가장 많은 업종(평균 21.3개)입니다. **점포가 많으면 개업·폐업 사건 자체가 많이 발생하고, 사건이 많으면 순감소로 잡힐 확률도 올라갑니다.** 즉 위험도를 재는 게 아니라 크기를 재고 있을 가능성이 있습니다.

**이 분석이 답하는 것:**

- **H2** — 골목상권에서 순감소 위험이 높은 업종에 대해, 점포 규모와 유동인구를 맞추면 타 업종과의 격차가 줄어드는가?
- **보조질문 2** — 매출·유동인구·점포 밀도 중 어떤 특성이 다음 분기 순감소 전환과 실제로 관련되는가?

**답이 바꾸는 행동:** 격차가 규모 교란에서 왔다면, 업종 단위 배정을 **칸(상권×업종) 단위 규모 조건부 배정**으로 바꿔야 합니다.

## 3. 데이터 개요 & 전처리 판단 요약

### 3-1. 데이터

서울 열린데이터광장 상권분석서비스 5개 테이블(점포·추정매출·영역·길단위인구·집객시설), 2023Q1 ~ 2026Q1 **13분기**.

| 단계 | 행 수 | 왜 이렇게 됐나 |
|---|---|---|
| 원본 점포 테이블 | 995,377 | 전체 업종 |
| 외식 10업종 × 13분기 | 160,352 | 분석 대상 업종만 |
| 라벨 생성 가능 | 147,138 | 다음 분기가 있어야 y 를 만듦 |
| **점포 5개 이상** | 67,495 | 아래 3-2 ① |
| **최종 분석 표본** | **67,475** | 유동인구·면적 유효 |

최종 표본 양성률(순감소) **25.5%**. 골목상권 PSM 입력은 이 중 골목상권만.

### 3-2. 전처리에서 내린 판단 (무엇을 했는지가 아니라 **왜 했는지**)

**① 점포 5개 미만 칸을 버렸다 — 주된 이유는 라벨 불안정성이다**
점포 3개짜리 칸은 1곳만 닫혀도 순감소 −33% 입니다. 이건 상권 악화 신호가 아니라 **표본 크기가 만든 잡음**이고, 그대로 두면 모형이 "위험한 상권"이 아니라 "작은 칸"을 학습합니다. **이게 1차 근거이고 데이터로 직접 확인됩니다.**
보조 근거로 매출 결측 패턴이 같은 방향을 가리킵니다 — 결측률 전체 45.4% → 점포 5개 이상 **7.1%** → 점포 2개 이하 **100%**. 다만 **이 100% 의 원인은 우리가 확인하지 못했습니다** (§3-3).

> **결측을 기준으로 행을 버린 게 아닙니다.** 버린 기준은 `점포_수` 라는 **공변량**이고, 종속변수 `net_decline` 은 매출 결측 여부와 무관하게 모든 칸에서 관측됩니다. 즉 결측된 행을 골라낸 게 아니라 **모집단을 좁힌 것**이므로, 추정 대상을 "점포 5개 이상 칸"으로 명시하는 한 통계적으로 유효합니다. 이 구분이 중요한 이유: 만약 결측 여부로 걸렀다면 결과와 상관된 선택이 되어 추정 자체가 편향됐을 것입니다.

대가: 라벨 생성 가능 147,138행 → 67,495행, **54.1% 를 잃습니다.** **그래서 결론은 "점포 5개 이상 칸에 한정"으로 범위를 명시합니다.**

**② `점포_수` 컬럼의 의미가 연도별로 다르다는 걸 발견하고 매핑을 고쳤다 — 이게 가장 큰 수정**
2023·2024 파일의 `점포_수` 는 총 점포수가 아니라 **비프랜차이즈 점포수**였습니다. 2025년 개편에서 이 컬럼이 `일반_점포_수` 로 개명되고 총수에 `전체_점포_수` 라는 새 이름이 붙은 것입니다. 항등식으로 100% 확인했습니다(`유사_업종_점포_수 = 점포_수 + 프랜차이즈_점포_수`, 일치율 1.0000).
수정 결과 표본이 55,795 → **67,475 (+20.9%)**, 증가폭은 업종마다 극단적으로 달랐습니다(치킨전문점 +390%, 한식음식점 +2%). **고치지 않았다면 프랜차이즈 비중이 높은 업종만 조직적으로 과소 집계된 상태로 업종 비교를 하는 셈이었습니다.**

**③ 매출을 매칭 공변량에서 뺐다 — 결측이 무작위가 아니기 때문**
매출 결측은 업종마다 다릅니다. 공변량에 넣으면 특정 업종 대조군만 선택적으로 탈락해 매칭 자체가 편향됩니다. 대신 보조질문 2(회귀)에서는 결측 표시 변수와 함께 사용하고, PSM 에서는 강건성 분석으로만 다룹니다.

**④ 상권 전체 점포수·외식 점포수는 업종 필터 *이전에* 계산했다**
필터 후에 계산하면 "이 상권에 가게가 몇 개인가"가 아니라 "우리가 남긴 가게가 몇 개인가"가 됩니다.

**⑤ 자치구 단위 파일 5종은 쓰지 않았다**
같은 구의 모든 상권이 동일 값을 가지므로 상권 간 변별력이 0 입니다. 매칭 공변량으로 쓸 수 없습니다.

**⑥ 라벨은 반드시 (상권, 업종) 그룹 안에서 분기 정렬 후 `shift(-1)`**
분기가 연속하지 않으면 라벨을 만들지 않습니다(140건 무효화). 그룹을 안 나누고 shift 하면 다른 상권의 미래를 가져옵니다.

**⑦ 학습에서 검증 분기(20254)를 뺐다**
행 하나는 (상권, 업종, 피처분기 t) 이고 라벨은 y(t) = [순감소 in t+1] 이라, 피처분기와 타깃분기가 한 칸 어긋납니다. 20254 를 학습에 넣으면 20261 결과를 미리 보게 됩니다.

```
용도   피처분기 t      타깃분기 t+1    라벨
학습   20231 ~ 20253   20232 ~ 20254   있음
검증   20254           20261           있음
예측   20261           20262           없음   ← 최종 산출물
```

### 3-3. 매출 결측 — 무엇을 했고, **무엇을 확인하지 않았나**

매출은 이 분석에서 가장 지저분한 변수입니다. 처리 자체는 보수적이지만 **진단이 부족합니다.** 면접·리뷰에서 반드시 나올 질문이라 별도 절로 분리해 둡니다.

**관측된 사실**

| 점포 수 구간 | 매출 결측률 | 성격 |
|---|---|---|
| 전체 | 45.4% | — |
| 5개 이상 (분석 표본) | **7.1%** | 규칙으로 설명 안 되는 **잔여 결측** |
| 2개 이하 | **100%** | 우연이 아님 — 규칙에 의한 처리 |

**우리가 한 처리 (방어 가능)**

1. **매출을 PSM 매칭 공변량에서 제외.** 결측률이 업종마다 다른데 업종이 곧 처치 변수입니다. 공변량에 넣었다면 결측 패턴이 처치 배정에 침투했을 것입니다 (§3-2 ③).
2. **대치(imputation)를 하지 않음.** 최종 모형(HistGradientBoosting)이 NaN 을 분기 규칙 안에서 직접 처리합니다. 대치를 했다면 **업종별로 다른 결측률이 대치값을 통해 편향으로 되돌아왔을** 것입니다 (§4-G-0 ②).
3. **핵심 인과 추정치는 매출에 의존하지 않음.** ATT −5.77%p 는 매출 없이 산출됩니다. 매출은 §4-G 예측 모형의 피처로만 들어갑니다 — **파급 범위가 좁습니다.**

**확인하지 않은 것 (한계로 명시)**

| # | 확인 안 한 것 | 왜 문제인가 |
|---|---|---|
| 1 | **잔여 7.1% 의 성격** | 점포 5개 이상인데도 매출이 빈 칸이 7.1% 있습니다. 점포 수 규칙으로 설명되지 않습니다. **결측 칸 vs 비결측 칸의 `net_decline` 비율 차이를 한 번도 재지 않았습니다.** MCAR 인지 MAR 인지 모릅니다 |
| 2 | **NaN 인가, 원본에 행이 없는가** | 우리는 (상권 × 업종 × 분기) 격자를 만들어 붙였습니다. 원본에 없던 조합도 격자가 채우면서 NaN 이 됩니다. 후자라면 **45.4% 는 원본의 결측률이 아니라 우리가 만든 격자의 빈칸 비율**이고 의미가 다릅니다. 확인 가능한 사실인데 확인하지 않았습니다 |
| 3 | **100% 결측의 *원인*** | "개별 사업자 식별 방지를 위한 비공개"는 **우리 추론이지 확인된 사실이 아닙니다.** 서울 열린데이터광장의 공식 비공개 기준 문구를 찾아 인용한 적이 없습니다. 경쟁 설명도 존재합니다 — "카드 매출이 잡히지 않는 영세 칸은 원본에 애초에 행이 없다"(비공개가 아니라 **미집계**). 두 설명은 같은 100% 를 만들지만 원인이 다릅니다 |
| 4 | **민감도 검사 부재** | 매출 피처를 빼면 / 결측 행을 버리면 / 대치하면 PR-AUC 0.417 이 얼마나 움직이는지 모릅니다 |

> ⚠️ **이전 판(§3-2 ①)에는 "점포 2개 이하는 100% 비식별 처리(개별 사업자 특정 방지)" 라고 단정형으로 적혀 있었습니다.** 근거보다 강한 문장이라 위와 같이 낮췄습니다. 검증 로그를 근거로 삼는 문서에 미검증 주장이 단정형으로 남으면 로그 전체의 신뢰도가 깎입니다.

**정리:** 5개 기준이라는 **결정은 결측 해석과 무관하게 성립합니다**(라벨 불안정성이라는 독립 근거가 있음). 문제는 결정이 아니라 **근거의 우선순위를 잘못 세우고, 검증 가능한 진단을 건너뛴 것**입니다. 다음 반복의 1순위 작업은 위 표의 #1·#2 — 둘 다 짧게 끝나는 확인입니다.

## 4. 발견 (Finding) — 사실만

### 0. 검정 방법은 우리가 고른 게 아니라 분포가 정했다

결과를 보기 전에, **어떤 검정을 쓸지부터 데이터에 물었습니다.** 정규성과 등분산성이 성립하면 ANOVA, 아니면 순위를 쓰는 비모수 검정입니다. 순서를 거꾸로 하면 안 됩니다.

**문제** — 라벨 `y` 는 0/1 이진값이라 여기에 정규성 검정을 걸면 의미가 없습니다. 이진 변수는 정의상 정규분포가 아니고, 표본만 크면 p 는 반드시 0 이 나옵니다.

**해결** — 검정 단위를 연속량으로 올렸습니다. **(상권 × 업종) 칸마다 12분기의 순감소 비율**을 계산하면 0~1 사이 연속값이 되고, 이게 그룹 간에 비교할 "위험 수준"의 자연스러운 단위입니다. 관측 6분기 미만 칸은 비율이 불안정해 제외했습니다 → **칸 5,687개**(제외 735개), 평균 0.249 · 중앙값 0.250 · **왜도 +0.592**.

| 비교 축 | 그룹 수 | 정규성 위배 | Levene p | 등분산성 |
|---|---|---|---|---|
| 상권유형 | 4 | **4/4** | <0.0001 | 위배 |
| 업종 | 10 | **10/10** | <0.0001 | 위배 |
| 자치구 | 25 | **25/25** | 0.0727 | 성립 |

**모든 그룹에서 정규성이 깨졌습니다.** 분포가 0 쪽에 몰리고 오른쪽 꼬리가 긴 형태(왜도 +0.592, 12분기 내내 순감소 0회인 칸이 7.1%)라, 평균을 비교하는 ANOVA 는 소수의 큰 값에 끌려갑니다. **그래서 주 검정을 Kruskal-Wallis 로 정했습니다.**

> **Shapiro-Wilk 검정** — 값이 정규분포를 따르는지 보는 검정. p < 0.05 면 정규분포가 아니라는 뜻.
>
> **Levene 검정** — 그룹 간 분산이 같은지 보는 검정. **중앙값 기준**으로 돌립니다 — 분포가 치우쳤을 때 평균 기준 Levene 은 그 자체로 왜곡되기 때문입니다.
>
> **Kruskal-Wallis 검정** — 값 자체가 아니라 **순위**로 그룹을 비교하는 방법. 정규성 가정이 필요 없습니다. 위 점검 결과가 이 선택의 근거입니다.

### A. 단순 격차는 애초에 실체가 없었다

한식음식점 순감소율 25.3%, 타 외식업 22.9%, **단순 격차 +2.4%p**.

**그런데 이 격차의 거의 전부가 "우리가 1위를 골랐다"는 행위의 산물입니다.**

> **순열검정** — 라벨 `y` 를 무작위로 섞으면 업종과 순감소의 관계가 완전히 끊어집니다(귀무가설). 각 업종의 표본 크기는 그대로 유지됩니다. 이 상태에서 `최고 업종 − 전체 평균` 을 1,000번 재면, 그 평균이 **"고르는 행위 자체가 만드는 격차"** 입니다. 왜 필요한가: 업종 간 차이가 정말 0 이어도 10개 중 최고는 우연히 위로 튀기 때문입니다.

| | 값 |
|---|---|
| 관측 (1위 한식 − 전체 평균) | +1.70%p |
| 귀무 ('10개 중 최고'가 그냥 만드는 격차) | **+1.49%p** (95% 범위 +0.53 ~ +2.94) |
| **순열 p값** | **0.344** |
| 한식 vs 나머지 척도로 환산한 선택 효과 | +2.10%p |
| **선택 효과를 뺀 실질 업종 차이** | **+0.29%p** |

**p = 0.344 — "한식이 순감소율 1위"라는 사실 자체가 통계적으로 유의하지 않습니다.** 관측 격차의 88%가 선택 효과로 설명됩니다.

이건 우리 결론을 약화시키는 게 아니라 **강화합니다.** 설명해야 할 현상은 "왜 한식이 위험한가"가 아니었습니다. 애초에 한식이 위험하지 않았고, 조건을 맞추자 −5.77%p 로 **뚜렷한 음수**가 나온 것이 유일하게 실재하는 신호입니다.

한편 규모 교란도 그대로 확인됩니다 — **점포수 구간을 나눠서 보면 모든 구간에서 한식이 더 안전합니다**(구간 내 평균 격차 −5.3%p). 전체에서는 높은데 모든 부분집단에서는 낮은, 전형적인 심슨의 역설입니다.

> ⚠️ 단 이건 **매칭 전** 층별 비교라, 각 구간 안에서도 처리·대조군의 조건이 여전히 다릅니다(Q5 는 처리 4,409칸 vs 대조 2,521칸). 짝을 지은 뒤 다시 층으로 나누면 그림이 달라집니다 — §4-B 뒷부분을 보세요.

> **심슨의 역설** — 전체 집계와 부분집단 집계의 방향이 반대로 나오는 현상. 여기서는 "한식은 점포가 많은 칸에 몰려 있고, 점포가 많은 칸이 순감소를 많이 겪는다"가 원인입니다.
>
> **ATT 는 이 선택 편향의 영향을 받지 않습니다** — 짝지은 쌍 안에서 계산하므로, 처리군을 어떻게 골랐든 "조건이 같은 두 칸의 차이"라는 성질은 유지됩니다.

### B. 조건을 맞추면 격차가 역전된다 — 4가지 방법이 모두 같은 답

| 방법 | 격차 | 통계량 |
|---|---|---|
| 매칭 전 단순 비교 | **+2.4%p** | 순열 p=0.344 — 유의하지 않음, 대부분 선택 효과 |
| ① 성향점수매칭 ATT | **−5.77%p** | 95% CI [−7.23, −4.23], McNemar p=5.0×10⁻¹⁵, 쌍 7,042 |
| ② 이중강건 추정 | **−6.15%p** | 매칭 + 회귀 보정 |
| ③ 반사실 시뮬레이션 | **−5.79%p** | 공변량 4개 전부 고정, 클러스터 부트스트랩 |
| ④ 대안 라벨(다음 분기 폐업률) | **−8.73%p** | 라벨을 바꿔도 부호 동일 |

민감도(캘리퍼·복원추출·시드 10개 설정) 전부에서 ATT 범위 **[−6.0%p, −4.0%p]** — 부호 일관.

> **PSM(성향점수매칭)** — 처리군(한식)과 조건이 비슷한 대조군(타 업종)을 1:1 로 짝지어 비교하는 방법. 왜: 관측 데이터에서 "다른 조건이 같다면"을 흉내내려고. 어떻게 읽나: 짝을 잘 지었는지부터 확인해야 하고, 그게 아래 SMD 입니다.
>
> **SMD(표준화 평균차)** — 두 그룹의 공변량이 얼마나 다른지를 표준편차 단위로 잰 값. **|SMD| < 0.1 이면 균형**으로 봅니다. 우리 결과: 점포수 SMD **1.00 → 0.037** (감소율 96.3%), 4개 공변량 전부 0.1 미만 → **균형 통과, ATT 해석 가능**.
>
> **ATT(처리군 평균 처리효과)** — 매칭된 짝들에서 (처리군 순감소율 − 대조군 순감소율). −5.77%p 는 "조건이 같은 칸끼리 비교하면 한식이 100칸당 5.77칸 덜 순감소한다"는 뜻.
>
> **McNemar 검정** — 짝지은 표본 전용 검정. 짝 중 한쪽만 순감소인 경우가 어느 방향으로 치우쳤는지 봅니다. p=5.0×10⁻¹⁵ ≪ 0.05 → **우연일 가능성 사실상 없음**.
>
> **클러스터 부트스트랩** — 같은 상권 안 칸들은 서로 닮았으므로, 재추출을 **상권 단위**로 합니다. 왜: 칸 단위로 재추출하면 표본이 실제보다 많은 척 되어 신뢰구간이 가짜로 좁아집니다.
>
> **이중강건 추정** — 매칭과 회귀 중 **하나만 맞아도** 편향이 사라지는 방식. 매칭값(−5.77)과 이중강건값(−6.15)이 가까우므로 잔여 불균형은 거의 없습니다.

**⚠️ 해석 범위 제한 ①:** 처리군 매칭률 **70.7%**. 나머지 29.3%(주로 초대형 한식 칸)는 짝을 찾지 못해 빠졌습니다. ATT 는 "비교 가능한 규모 구간에 한정된 효과"입니다.

#### 그 평균을 하나의 숫자로 말해도 되는가 — 아니오 ★

**평균은 서로 반대 방향인 값들을 섞어 놓아도 하나의 숫자를 만들어 냅니다.** 그래서 −5.77%p 를 보고하기 전에 그것이 요약으로서 성립하는지 확인했습니다. 매칭된 7,042쌍을 점포수 5분위로 나눈 결과:

| 층 | 쌍수 | 평균 점포 | 한식 순감소율 | 대조군 순감소율 | **층별 ATT** | 오즈비 |
|---|---|---|---|---|---|---|
| Q1 | 1,409 | 5.9 | 12.5% | 25.5% | **−13.0%p** | 0.42 |
| Q2 | 1,408 | 8.7 | 16.4% | 26.8% | −10.4%p | 0.54 |
| Q3 | 1,408 | 12.8 | 22.1% | 28.7% | −6.6%p | 0.70 |
| Q4 | 1,408 | 19.6 | 27.9% | 29.2% | −1.3%p | 0.94 |
| **Q5** | 1,409 | 38.5 | 36.5% | 34.1% | **+2.4%p** | 1.11 |

**Woolf 동질성 검정 Q = 78.686 (df=4), p < 0.0001 → 층별 효과가 서로 다릅니다.**

> **Woolf 동질성 검정** — 층마다 구한 오즈비가 서로 같다고 볼 수 있는지 보는 검정. **여기서는 p 가 크기를 바라는 검정**입니다. p 가 작으면 "층마다 효과가 다르다"는 뜻이라, 하나의 평균으로 요약할 수 없게 됩니다. 왜 필요한가: 평균 하나만 보고하면 방향이 반대인 구간이 숨어 버립니다.

**⚠️ 해석 범위 제한 ②:** 층별 ATT 가 **−13.0%p 에서 +2.4%p 까지 단조롭게 이동하며 Q5 에서 부호가 바뀝니다.** 따라서 정확한 진술은 이렇습니다.

> **작은 칸일수록 한식이 뚜렷하게 안전하고, 점포 20개(Q4)를 넘으면 그 이점이 사라지며, 40개에 가까운 칸에서는 오히려 약간 불리하다.**

**H2 판정은 바뀌지 않습니다** — "격차가 줄어든다"는 예측은 어느 층에서도 맞지 않았고, 규모 교란이 단순 격차를 만들었다는 결론도 그대로입니다. 바뀌는 것은 **적용 범위**입니다. 발표에서 −5.77%p 를 인용할 때는 반드시 이 표를 함께 걸어야 합니다.

*(참고 — 이 층별 ATT 는 실제 매칭 쌍을 나눈 값입니다. `h2_dose_response.csv` 의 용량-반응 곡선은 반사실 모형이 점포수 값을 바꿔가며 예측한 값이라 성격이 다릅니다. 둘을 섞어 인용하지 마세요.)*

### C. 역전을 만든 건 점포 규모 하나. 유동인구는 아무 기여도 없다

반사실 시뮬레이션 — 공변량을 하나씩만 고정했을 때 격차가 어떻게 변하는가:

| 고정한 변수 | 예측 격차 | 해석 |
|---|---|---|
| 아무것도 안 함 | +3.07%p | 원래 상태 |
| **점포 규모만** | **−5.74%p** | **혼자서 역전을 다 만듦** |
| 유동인구만 | +3.57%p | 오히려 살짝 증가 — 기여 0 |
| 면적만 | +3.20%p | 기여 없음 |
| 점포당매출만 | +6.09%p | 반대 방향 |
| 규모 + 유동인구 (H2 명시) | −5.49%p | 규모 단독과 사실상 동일 |
| 공변량 4개 전부 | −5.79%p | 규모 단독과 사실상 동일 |

**H2 가 명시한 두 변수 중 유동인구는 역할이 없었습니다.**

보조질문 2 회귀(클러스터 로버스트 표준오차, n=67,475):

| 변수 | AME | p값 | 판정 |
|---|---|---|---|
| **log_점포수** | **+14.28%p** | 2.8×10⁻¹⁶⁴ | *** 압도적 1위 |
| 외식_비중 | −13.84%p | 5.2×10⁻⁶ | *** |
| log_면적 | −1.39%p | 0.032 | * 미미 |
| log_집객시설 | −1.24%p | 0.0097 | ** 미미 |
| **log_유동인구** | **+0.72%p** | **0.078** | **유의하지 않음** |

> **AME(평균 한계효과)** — "그 변수가 1 단위 올라가면 순감소 확률이 몇 %p 움직이는가". 왜: 로지스틱 계수나 오즈비는 감이 안 오는데 %p 는 바로 읽힙니다. 어떻게 읽나: +14.28%p = 점포수가 e배(약 2.7배) 되면 순감소 확률이 14.3%p 오릅니다.
>
> **p값** — "효과가 진짜 0인데 우연히 이만큼 나올 확률". 0.05 미만이면 유의하다고 봅니다. 유동인구 0.078 은 **기준을 못 넘겼습니다** — "약한 효과가 있다"가 아니라 "0과 구별 안 된다"로 읽어야 합니다.
>
> **클러스터 로버스트 표준오차** — 같은 상권 관측치끼리의 상관을 인정하고 표준오차를 넓히는 보정. 안 하면 p값이 가짜로 작아집니다.

### D. 유동인구가 무의미한 이유 — 두 겹으로 확인

**① 순감소는 개업과 폐업의 *차이*라서, 둘을 같은 방향으로 미는 변수는 사라진다.**
개업·폐업을 따로 음이항 회귀로 놓고 보면:

| | 개업 계수 | 폐업 계수 | 방향 |
|---|---|---|---|
| log_유동인구 | **+0.098** (p=7.0×10⁻⁵) | **+0.053** (p=0.0095) | **같음** |
| log_점포수 | −0.099 (p=1.5×10⁻⁵) | +0.065 (p=0.0010) | 반대 |
| 외식_비중 | +0.472 (p=0.0015) | −0.484 (p=1.3×10⁻⁴) | 반대 |

유동인구는 개업도 늘리고 폐업도 늘립니다. 차이로 보면 약 70%가 상쇄됩니다. **유동인구가 많은 상권은 위험한 게 아니라 회전이 빠른 상권입니다.**

> **음이항 회귀 + log(점포수) 오프셋** — 건수(0,1,2…)를 다루되 점포수로 나눈 **비율**을 모형화하는 방법. 왜: 가게 100개인 칸에서 폐업 2건과 가게 5개인 칸에서 폐업 2건은 전혀 다른 사건이라서. 과분산 비 개업 1.81 / 폐업 1.65 (>1) → 포아송 대신 음이항이 맞습니다.

**② 칸 고정효과를 걸면 유동인구는 완전한 무효과.**
같은 (상권×업종) 칸 안에서 시간에 따라 유동인구가 오르내릴 때 개업·폐업 비율이 움직이는지 봤습니다 → **개업 p=0.865, 폐업 p=0.963**. 완벽한 null.

> **칸 고정효과** — 칸마다 고유의 "체질"을 통째로 빼내고, 같은 칸 안의 시간 변화만으로 효과를 추정하는 방법. 왜: 상권마다 다른 임대료·접근성·상권 나이 같은 **관측 안 되는 시간불변 요인**을 전부 제거하려고. 결과 해석: 횡단면에서 보이던 유동인구-폐업 연관은 **입지의 시간불변 특성이 만든 것**이지 유동인구 자체의 효과가 아닙니다.

### E. "규모가 위험하다"조차 상당 부분은 라벨의 산술이다

점포수 구간별로 뜯어보면:

| 점포수 | 칸 수 | 다음 분기 사건(개업 또는 폐업) 발생률 | 순감소율 | **사건이 있는 칸만 보면 순감소율** |
|---|---|---|---|---|
| 5개 | 5,487 | 29.1% | 14.6% | **50.1%** |
| 8-10개 | 6,295 | 45.4% | 21.3% | 47.0% |
| 16-25개 | 4,262 | 73.9% | 31.9% | 43.2% |
| 51개+ | 825 | 97.9% | 37.7% | **38.5%** |

작은 칸은 순감소율이 낮은 게 아니라 **아무 일도 안 일어나서** 0 으로 기록됩니다(전체 표본의 43.7%가 무사건 칸).

**⚠️ 위 표는 무보정 값입니다.** 규모가 큰 칸은 업종 구성도 상권 성격도 다르므로, 마지막 열의 하락(50.1% → 38.5%)에는 그 차이가 섞여 있습니다. 두 단계를 각각 회귀로 분리하면:

> **2단계 분해** — P(순감소) = P(사건 발생) × P(순감소 given 사건). 근사가 아니라 **정확한 등식**입니다. 순감소는 반드시 사건의 부분집합이라 P(순감소 given 사건 없음) = 0 이기 때문이고, 실측으로 확인했습니다(15,451칸 중 y=1 이 **0건**, 0.5153 × 0.4582 = 0.2361 = 실제값). 왜 나누는가: 규모 편향이 어느 단계에 갇혀 있는지 보려고.

| 단계 | log_점포수 계수 (공변량·업종 보정, 클러스터 SE) | n |
|---|---|---|
| 1단계 P(사건 발생) | **+1.483** (p < 0.001) | 31,875 |
| 2단계 P(순감소 given 사건) | **+0.046** (p = 0.114) | 16,424 |

**규모 효과는 사실상 전부 1단계에 갇혀 있습니다.** 보정 후 2단계 계수는 0과 구별되지 않으므로, 정확한 문장은 "큰 칸이 오히려 안전하다"가 아니라 **"조건을 맞추면 큰 칸이 더 위험하지는 않다"** 입니다.

**즉 순감소율은 위험도가 아니라 "사건이 발생할 만큼 큰가"를 재고 있습니다.**

### F. 업종마다 "입지에 민감한 정도"가 다르다

여기까지는 업종을 하나로 묶어 봤습니다. 그런데 **어떤 업종은 어디에 있느냐가 크게 중요하고, 어떤 업종은 전혀 중요하지 않습니다.**

**업종을 하나로 고정한 뒤 그 안에서만** 상권유형 간 차이를 검정했습니다(§4-0 에서 정한 Kruskal-Wallis). 전체를 한 번에 검정하면 특정 유형에 특정 업종이 몰려 있을 때 유형 효과와 업종 효과가 붙어 버리기 때문입니다.

| 업종 | n | H | p | **ε²** | 판정 |
|---|---|---|---|---|---|
| **호프-간이주점** | 709 | 86.9 | <0.0001 | **0.1202** | 중간 — 입지에 가장 민감 |
| 커피-음료 | 1,006 | 67.4 | <0.0001 | 0.0652 | 중간 |
| 한식음식점 | 1,306 | 81.0 | <0.0001 | 0.0607 | 중간 |
| 양식음식점 | 352 | 18.8 | 0.0001 | 0.0483 | 작음 |
| 분식전문점 | 637 | 32.5 | <0.0001 | 0.0481 | 작음 |
| 일식음식점 | 307 | 15.6 | 0.0004 | 0.0448 | 작음 |
| 제과점 | 347 | 12.9 | 0.0015 | 0.0318 | 작음 |
| 중식음식점 | 302 | 11.0 | 0.0041 | 0.0300 | 작음 |
| 패스트푸드점 | 322 | 7.1 | 0.0281 | 0.0161 | 작음 *(보정 후 비유의)* |
| **치킨전문점** | 341 | 2.1 | 0.3552 | **0.0002** | **무시할 수준 — 어디 있든 같음** |

Bonferroni 보정 α = 0.0050 · **유의 8/10**.

> **ε² (엡실론 제곱)** — Kruskal-Wallis 의 효과크기. "그룹이 다르다는 사실이 전체 변동의 몇 %를 설명하는가". **0.01 작음 / 0.06 중간 / 0.14 큼**으로 읽습니다.
>
> **Bonferroni 보정** — 같은 검정을 10번 반복하면 우연히 유의해지는 경우가 생깁니다. 기준을 10배 엄격하게(α = 0.05/10) 만들어 막습니다.
>
> **왜 p 가 아니라 효과크기로 판정하나** — 표본이 수천 개라 아주 작은 차이도 p 는 유의하게 나옵니다. p 는 "차이가 있나"에만 답하고 "쓸 만한 크기인가"에는 답하지 않습니다. 이 표를 **효과크기 순으로 정렬한 이유**입니다.

**"모든 업종이 입지에 민감하다"는 진술은 성립하지 않습니다.** 호프-간이주점(0.1202)과 치킨전문점(0.0002) 사이에 **600배** 차이가 있습니다. 치킨은 어디에 있든 위험 수준이 비슷하므로, **상권 단위 대응 자체가 효과를 내기 어렵습니다** — 배달 비중이 높아 입지 의존이 낮은 업태의 성질로 보입니다(다만 이 분석이 배달 데이터를 본 건 아니라 추정입니다).

### G-0. 모델 선택 — 왜 부스팅인가 (그리고 그게 결론을 바꾸지 않는 이유)

**리더보드 (검증분기 20254, `outputs/pred_leaderboard.csv`)**

| B | 직전분기 상태 | 0.531 | 0.274 | 0.218 | 0.634 |
| C | 업종 평균 | 0.554 | 0.291 | 0.191 | 0.570 |
| D | 로지스틱 | **0.670** | 0.407 | 0.180 | 0.540 |
| **E** | **부스팅 (HistGradientBoosting)** | 0.668 | **0.417** | **0.179** | **0.539** |

```
PR-AUC ─ 검증분기 20254                          무작위 기준선 = 양성률 0.260
A 항상 평균      0.260  ██████████

   D~F 서로의 간격            : +0.011   ← 여기가 "부스팅을 고른 값어치"
```

**선택 논리 4가지**

**① 선택 지표를 PR-AUC 로 잡았다 — 정확도도 F1 도 아니다.**
AUC 만 보면 로지스틱(0.670)이 부스팅(0.668)보다 근소하게 낫습니다. 그런데 이 문제의 실제 사용처는 **위험 상위 K칸을 뽑아 지원 대상으로 삼는 것**(§4-I)이고 양성률은 26%로 불균형입니다. 이 운영 지점에서 의미 있는 건 **양성 클래스의 정밀도-재현율**이지 전체 순위 품질이 아닙니다. PR-AUC 에서는 0.417 vs 0.407 로 부스팅이 앞섭니다.
**정확도(accuracy)를 쓰지 않은 이유:** "전부 안전"이라고 찍으면 74.0% 가 나옵니다 — 아무 정보도 없는 모형이 이깁니다.
**F1 을 쓰지 않은 이유:** F1 은 임계값 하나에 결과가 매달려 **임계값 선택이 곧 결론**이 됩니다. 임계값은 예산이 정하는 것이지 모형이 정할 게 아니라서, 임계값과 무관한 지표(PR-AUC)로 고르고 임계값은 §4-I 에서 예산 시나리오별로 따로 다룹니다.

**② 결측을 대치 없이 통과시킬 수 있다 — 이게 실질적으로 가장 큰 이유.**
`log_점포당매출` 에 NaN 이 7.1% 남아 있습니다(§3-3). HistGradientBoosting 은 결측을 분기 규칙 안에서 직접 처리합니다. 로지스틱·랜덤포레스트를 쓰려면 대치가 필요하고, **결측률이 업종마다 다르므로 대치는 업종별 편향을 새로 만듭니다** — 하필 업종이 이 분석의 처치 변수입니다. 번들에 `needs_impute: BEST != "E 부스팅"` 을 기록한 게 이 뜻입니다: 부스팅이 아닌 모형을 고르는 순간 파이프라인에 대치 단계가 **강제로** 추가됩니다.

**③ 확률값 자체가 쓸 만하다 (Brier 0.179, LogLoss 0.539 — 둘 다 최저).**
우리는 순위만 쓰는 게 아닙니다. 2단계 분해 `P(순감소) = P(사건) × P(순감소 | 사건)` (§4-E)에서 확률값을 직접 씁니다. 순위만 맞고 확률이 어긋나면 그 분해가 깨집니다.

**④ 비선형·상호작용을 손으로 설계하지 않아도 된다.**
층별 ATT 가 −13.0%p(점포 5.9개) ~ +2.4%p(점포 38.5개)로 **부호까지 바뀝니다**(§4-B). 점포 수 효과가 단조롭지 않다는 뜻입니다. 로지스틱으로 잡으려면 구간 더미·교호항을 수작업으로 넣어야 하고, **그 설계 자체가 연구자 자유도**가 됩니다.

**⑤ 그리고 정직하게 — D·E·F 의 차이는 사실상 잡음입니다.**

롤링 오리진 6분기(`outputs/pred_rolling.csv`)에서 두 모형을 나란히 재면:

| 검증분기 | 부스팅 AUC | 로지스틱 AUC | 승자 |
|---|---|---|---|
| 20243 | 0.654 | 0.661 | 로지스틱 |
| 20244 | 0.674 | 0.670 | 부스팅 |
| 20251 | 0.652 | 0.645 | 부스팅 |
| 20252 | 0.671 | 0.668 | 부스팅 |
| 20253 | 0.677 | 0.674 | 부스팅 |
| 20254 | 0.668 | 0.670 | 로지스틱 |
| **평균** | **0.6661** | **0.6645** | 부스팅 **+0.0016** |

부스팅이 6분기 중 **4분기**에서 앞섰지만 평균 차이는 **+0.0016** 입니다. 같은 기간 부스팅 자신의 PR-AUC 는 **0.392 ~ 0.445 (폭 0.053)** 로 흔들립니다 — **분기 간 변동이 모형 간 차이(0.011)의 5배**입니다. 동료가 독립적으로 5개 모형 계열을 돌려 AP 0.398~0.408 을 얻은 것도 같은 결론을 지지합니다.

> **그래서 정확한 서술은 이것입니다.** "부스팅을 써서 성능이 좋아졌다"가 아니라 —
> **"부스팅은 결측을 손대지 않고 통과시키면서 PR-AUC·Brier·LogLoss 에서 근소하게 앞섰고, 성능의 실제 병목은 모형이 아니라 피처였다."**
> 근거: 모형 교체로 얻은 건 +0.011(PR-AUC), 피처 추가로 얻은 건 AUC 0.705 → 0.717 (+0.012)에 포아송 이탈도 1.002 → 0.976(§4-G). **모형 계열은 이 프로젝트의 어떤 결론도 좌우하지 않습니다.**

> ⚠️ **《검증값》과 《롤링》은 성질이 다릅니다.** 0.668·0.417·0.179 는 20254 분기에서 잰 값인데, **바로 그 표를 보고 모델을 골랐습니다.** 결정에 쓴 점수는 낙관 쪽으로 치우칩니다. 학습 종료 분기를 밀어가며 6번 잰 롤링 AUC **0.666 ± 0.010** 이 편향 없는 추정이고, 발표에는 이 값을 씁니다. 두 값이 거의 같다는 사실 자체가 "치우침이 크지 않다"는 증거입니다.

> **AUC** — 무작위로 고른 "위험한 칸"과 "안전한 칸" 한 쌍에서 모형이 위험한 쪽에 더 높은 점수를 줄 확률. 0.5 는 동전 던지기, 1.0 은 완벽. 0.668 은 "순위 매기기에는 쓸 만하지만 개별 예측을 믿을 수준은 아님".
>
> **PR-AUC** — 양성이 드물 때 AUC 보다 정직한 지표. 무작위 기준선이 양성률(0.260)이므로 0.417 은 **기준선의 1.61배**로 읽습니다.
>
> **Brier 점수** — 예측 확률과 실제(0/1) 차이의 제곱 평균. 순위가 아니라 **확률값 자체가 맞는지**를 봅니다.
>
> **포아송 이탈도** — 건수 예측 전용 오차. **1.0 미만이면 "점포수만 쓴 예측보다 낫다"**는 뜻. 0.976 은 개선폭이 작다는 뜻이기도 합니다.
>
> **리프트(십분위)** — 위험 예측 상위 10% 칸의 실제 폐업률 ÷ 전체 평균. 1.52배 = 그 10%만 골라 지원하면 무작위 배정보다 1.5배 많은 실제 폐업 예정 점포에 닿습니다. **이게 실무에서 제일 쓸모 있는 숫자입니다.**
>
> **베이스라인 사다리(B1/B2/B3)** — B1 점포수만 / B2 업종 과거평균 / B3 우리 모형 순으로 올려가며 "우리가 실제로 보탠 게 얼마인지" 재는 방법. 왜: 절대 성능은 문제 난이도에 따라 달라서 그 자체로는 의미가 없기 때문. **결과: B1 0.705 → B3 0.717.** 전체를 줄 세우는 능력만 보면 +0.012 로 작습니다. 다만 그 값어치가 어디에 몰려 있는지는 아래 H·I 를 봐야 합니다.

### H. 외부 기준선 — 서울시 공식 상권변화지표는 무작위보다 못하다

지금까지의 베이스라인은 전부 우리가 만든 것이었습니다. **실무에서 실제로 쓰이는 판단 도구**와 비교해야 도입 근거가 생깁니다.

서울시 상권분석서비스는 상권마다 분기별로 상권변화지표(HH·HL·LH·LL)를 부여합니다. **HL = 상권축소** 진단으로 다음 분기 순감소를 찍어 보면:

| 지표 | 칸수 | 순감소율 | Lift |
|---|---|---|---|
| **HL (상권축소)** | 974 | 24.3% | **0.937** |
| HH | 1,452 | 23.3% | 0.899 |
| LH | 790 | 22.9% | 0.882 |
| LL | 2,263 | 29.4% | 1.133 |

**「상권축소」 진단을 받은 상권이 오히려 평균보다 덜 순감소합니다(Lift 0.937 < 1).** 이 지표만으로는 다음 분기를 맞히지 못합니다.

> ⚠️ 이 지표는 **기준선으로만** 씁니다. 폐업 정보로 만들어져 라벨과 원천이 같아, 피처로 넣으면 누수입니다.
>
> 같은 파일의 `운영_영업_개월_평균`(영업 **중인** 점포 기준이라 원천이 다름)은 피처 후보가 될 수 있어 확인했습니다 — 단변량 AUC **0.538**, log_점포수와 상관 **−0.085**(규모의 대리변수 아님), 5분위 순감소율 29.9% → 22.2% 단조 감소. **약하지만 방향은 있습니다.** 이번 모형에는 넣지 않았고, 후속에서 추가할 만한 변수로 기록합니다.

### I. 운영 관점 성능 — 몇 칸을 찍을 것인가

AUC 는 **전체를 줄 세우는 능력**입니다. 그런데 실제 운영은 전체를 지원하지 않습니다. 손이 닿는 수십~수백 곳을 찍습니다. **그 구간이 실무 성능**입니다. 비교 대상은 가장 강력한 단순 규칙 — "점포 수가 많은 순서대로 찍기".

| 찍은 칸수 | 모델 정밀도 | 점포수 규칙 정밀도 | 모델 Lift | **두 목록 겹침** |
|---|---|---|---|---|
| **50** | **0.760** | 0.380 | **2.93** | **6%** |
| 100 | 0.620 | 0.460 | 2.39 | 16% |
| 200 | 0.555 | 0.520 | 2.14 | 32% |
| 500 | 0.498 | 0.468 | 1.92 | 56% |
| 2,000 | 0.393 | 0.385 | 1.51 | 85% |

**상위 50칸에서 정밀도 0.760 대 0.380 — 두 배 차이이고 목록이 6%만 겹칩니다.** 서로 완전히 다른 상권을 지목한다는 뜻입니다. 많이 찍을수록 두 방법이 수렴하는 건, 많이 찍으면 결국 큰 상권을 다 담게 되기 때문입니다.

> **목록 겹침률** — 모델이 찍은 K칸과 점포수 규칙이 찍은 K칸의 교집합 비율. 왜: "모델이 결국 점포 수를 다시 쓰는 것 아니냐"는 가장 흔한 반박을 직접 반증하는 숫자라서. 6% = 거의 겹치지 않음.

**규모를 고정해도 모델이 이깁니다.** 점포 수가 비슷한 칸들끼리 묶으면 점포 수는 더 이상 정보를 줄 수 없습니다. 그 안에서도 순위를 매기는지가 진짜 질문입니다.

| 규모구간 | 평균 점포 | 기저율 | 모델 Lift | 점포수 Lift |
|---|---|---|---|---|
| Q1 | 5.3 | 15.0% | **1.345** | 1.100 |
| Q2 | 7.3 | 18.4% | **1.343** | 1.101 |
| Q3 | 11.0 | 21.9% | **1.464** | 1.160 |
| Q4 | 18.8 | 30.8% | **1.266** | 1.142 |
| Q5 | 64.5 | 43.7% | **1.175** | 1.075 |

**다섯 구간 전부 모델이 높고, 격차는 작은 구간에서 가장 큽니다.** 기저율이 Q1 15.0% → Q5 43.7% 로 2.9배 벌어져 있다는 점도 중요합니다 — "점포 수" 규칙은 큰 칸만 골라도 자동으로 기저율 높은 구간에 들어앉습니다. **위험을 읽은 게 아니라 위험이 흔한 구간을 고른 것**이고, 그래서 전체 성능이 부풀려 보입니다.

**§G 의 "+0.012" 는 전체 줄 세우기 기준입니다. 층화해서 보면 모델의 값어치는 조기경보가 실제로 필요한 작은 상권 구간에 몰려 있습니다.**

**⚠️ 쓰면 안 되는 숫자 — 업종 순위상관 0.515**
초기에 "업종 순위 예측 상관 0.915" 라는 값이 나와 성능 근거로 쓸 뻔했습니다. 점검 결과 그 값은 **점포수 하나만 넣어도 똑같이 나왔습니다**(B1 이 동일 점수). 그래서 목표값 자체의 신뢰도를 쟀습니다.

> **반분 신뢰도(split-half reliability)** — 같은 데이터를 무작위로 반씩 쪼개 각각 업종 순위를 만들고, 두 순위가 서로 얼마나 일치하는지 보는 값. 왜: **모형이 아무리 좋아도 정답 자체가 흔들리면 그 이상 맞출 수 없기 때문.** 결과: 반쪽 상관 **+0.110**, Spearman-Brown 보정 후 **0.198**, 5~95% 범위 **−0.36 ~ +0.54**.
>
> **이론적 상한 = √신뢰도 = √0.198 = 0.444.** 완벽한 예측기라도 이 값을 못 넘습니다.

우리 모형의 업종 순위상관 **0.515 > 상한 0.444** → **실력이 아니라 잡음**입니다. 발표에서 성능 근거로 쓰지 않습니다. **성능 근거는 칸 단위 지표(AUC 0.717 / 리프트 1.52배)만 씁니다.**

## 5. 인사이트 (Insight) — 그래서 무슨 뜻인가

**① 현재 서울시가 쓰는 순감소 지표는 위험도 지표가 아니라 규모 지표다.**
순감소 = 개업 − 폐업 < 0 이라는 정의가, 사건이 자주 일어나는 큰 칸을 자동으로 위쪽에 올립니다. 한식이 매 분기 1위인 건 한식이 위험해서가 아니라 한식 칸이 크기 때문입니다(§4-A, §4-E). **지표가 답을 미리 정하고 있었습니다.**
같은 서비스의 공식 상권변화지표도 다음 분기를 못 맞힙니다(HL Lift 0.937, §4-H). **지금의 판단 도구 두 개가 모두 작동하지 않는다는 뜻입니다.**

**② "유동인구 많은 곳에 창업하라"는 상식은 절반만 맞다.**
유동인구는 개업도 폐업도 함께 늘립니다(§4-D①). 사람이 많은 곳은 **안전한 곳이 아니라 회전이 빠른 곳**입니다. 게다가 같은 칸 안에서 유동인구가 변해도 개업·폐업은 안 움직입니다(§4-D②) — 즉 유동인구는 **입지의 대리 변수**일 뿐, 그 자체가 원인이 아닙니다.

**③ 업종을 고르는 것보다 규모를 맞추는 게 중요하다 — 단, 그 이점은 작은 칸에만 있다.**
조건이 같으면 한식은 안전한 축입니다(ATT −5.77%p, 폐업률 9위). 업종 라벨로 위험을 판단하면 틀립니다.
그런데 층별로 보면 그 이점이 **점포 6개 칸에서 −13.0%p 로 크고, 20개를 넘으면 사라지며, 40개 부근에서는 오히려 역전됩니다**(§4-B). 실제 신호는 업종도 규모도 아닌 **(업종 × 규모) 조합**에 있습니다. **"한식은 안전하다"도 "한식은 위험하다"도 둘 다 틀린 문장입니다.**

**③-b 업종마다 입지가 중요한 정도가 다르다.**
호프-간이주점은 상권유형에 따라 위험이 크게 갈리고(ε²=0.1202), 치킨전문점은 어디에 있든 같습니다(ε²=0.0002) — **600배 차이**. 같은 지원 수단을 모든 업종에 똑같이 적용하면 안 됩니다. 입지 기반 대응이 통하는 업종과 안 통하는 업종이 갈립니다(§4-F).

**④ 데이터가 답할 수 있는 최소 단위는 "칸"이고, 그 아래로는 답할 수 없다.**
자치구×업종 단위는 반분 신뢰도가 0.035 로, **정답 자체가 재보면 뒤바뀝니다.** 이 단위 순위표는 만들면 안 됩니다(만들면 잡음을 발표하는 것).

**⑤ 모델의 값어치는 "전체 순위"가 아니라 "작은 상권을 골라내는 데" 있다.**
전체를 줄 세우는 능력만 보면 점포 수 하나와 큰 차이가 없습니다(+0.012). 그런데 규모를 고정하면 점포 수는 아무 정보도 못 주는 반면 모델은 여전히 순위를 매깁니다 — Q1 구간 Lift 1.345 대 1.100(§4-I). **조기경보가 실제로 필요한 곳이 바로 그 작은 상권 구간입니다.** 전체 지표만 보고 "모델 필요 없다"고 결론 내리면 정반대로 읽는 것입니다.

| **적용 범위** | 골목상권 · 점포 5개 이상 칸 · 외식 10업종에 한정. 발달상권·전통시장은 재학습 필요 |
| **매칭 커버리지** | 처리군 매칭률 70.7%. 초대형 한식 칸(29.3%)은 짝이 없어 결론 밖 |
| **ATT 는 단일 숫자가 아니다** | Woolf 동질성 검정 p<0.0001. 층별 ATT 가 −13.0%p(점포 6개) ~ +2.4%p(점포 39개)로 **부호까지 바뀝니다.** −5.77%p 를 단독 인용하면 방향이 반대인 구간을 숨기는 것이 됩니다 (§4-B) |
| **입지 민감도 검정의 표본** | §4-F 는 관측 6분기 이상 칸 5,687개 기준입니다. 업종별 n 이 302~1,306 으로 편차가 커, n 이 작은 업종(중식 302·일식 307)의 효과크기는 상대적으로 불안정합니다 |
| **관측 단위의 벽** | 상권×업종 **집계** 데이터라 "어느 점포가 닫혔는지"를 모릅니다. 폐업 건수의 대부분은 개별 점포 사정인데 그 정보가 없습니다 |
| **인과 주장의 한계** | PSM 은 **관측된** 공변량만 맞춥니다. 임대료·점주 연령·업력·자본금 같은 미관측 교란은 남아 있습니다 |
| **자치구×업종 단위 불가** | 반분 신뢰도 0.035 — 이 단위 순위는 잡음. 칸 단위 예측은 저장돼 있으니 집계는 가능하지만 **검증이 불가능**합니다 |
| **불확실성 구간의 성격** | 부트스트랩 CI 는 표본 흔들림만 담습니다. 모형이 틀릴 가능성은 빠져 있어 **실제 불확실성은 더 넓습니다** |
| **예측 성능의 솔직한 크기** | 전체 줄 세우기 기준으로 칸 AUC 0.717 중 0.705 는 점포수만으로 나옵니다(+0.012). 값어치는 층화·상위구간에 몰려 있습니다(§4-I) |
| **`영역_면적` 정의 불명** | 원본 문서에 정의가 없습니다. 점포당 면적 중앙값 400㎡대·최대 상권 2.46km² 로 보아 **상업 용도가 아닌 폴리곤 전체 면적**으로 해석했으나 **확인된 사실이 아닙니다.** 이 변수는 PSM 공변량 4개 중 하나입니다 (다만 반사실에서 면적만 고정 시 격차가 +3.07 → +3.20%p 로 거의 안 움직여 결론이 여기 의존하지는 않습니다) |
| **매출 결측을 진단하지 않았다** | 처리(매칭 공변량 제외·무대치)는 보수적이지만 **진단이 없습니다.** ⑴ 점포 5개 이상에 남은 잔여 결측 7.1% 가 결과와 상관되는지 재지 않았고, ⑵ NaN 인지 원본에 행이 없는지 구분하지 않았으며, ⑶ 100% 결측의 원인("식별 방지 비공개")은 **확인된 사실이 아니라 우리 추론**이고, ⑷ 매출 피처 유무에 대한 민감도 검사가 없습니다. 다만 핵심 인과 추정치(ATT)는 매출을 쓰지 않아 파급 범위는 §4-G 예측 성능에 한정됩니다 (§3-3) |
| **모형 선택 근거의 실제 크기** | 부스팅 선택의 성능 근거는 PR-AUC +0.011(로지스틱 대비)뿐이고, 롤링 6분기 평균 AUC 차이는 **+0.0016** 입니다. 같은 기간 분기 간 PR-AUC 변동폭이 0.053 으로 **모형 간 차이의 5배**입니다. 부스팅을 고른 실질적 이유는 성능이 아니라 **결측 무대치 처리**이며, 다른 모형을 골라도 결론은 바뀌지 않습니다 (§4-G-0) |
| **홀드아웃 분기 없음** | 20254 를 검증에 쓰면서 그 표로 모델을 골랐습니다. 별도의 "한 번만 보는" 테스트 분기를 두지 않았습니다. 롤링 6분기(0.666 ± 0.010)가 대체 근거이고 검증값과 거의 같지만, **다음 반복에서는 분기 하나를 완전히 봉인해 두는 게 맞습니다** |
| **단일 분기 평가의 한계** | 반분 신뢰도가 단일 분기에서는 자치구 0.086 / 자치구×업종 0.035 로 매우 낮습니다. 6분기를 풀링하면 0.537 / 0.259 로 올라갑니다. **어떤 집계 단위든 한 분기로 순위를 매기지 마세요** |

### 후속 분석 (다음에 무엇이 있으면 답이 뚜렷해지는가)

**0순위 — 매출 결측 진단 (비용 거의 0, 지금 당장 가능).** 외부 데이터가 필요 없는 유일한 항목이라 맨 앞에 둡니다. ⑴ 원본 CSV 에서 (상권×업종×분기) 조합이 실제로 존재하는지 세어 **NaN 인지 행 부재인지** 확정, ⑵ 잔여 결측 7.1% 칸과 비결측 칸의 `net_decline` 비율 차이 검정, ⑶ 매출 피처를 뺀 모형과 PR-AUC 비교, ⑷ 서울 열린데이터광장 메타데이터에서 **비공개 기준 문구를 찾아 인용하거나, 없으면 "확인 불가"로 확정.** 결과에 따라 §3-2 ①의 근거 서술을 라벨 불안정성 하나로 재정렬합니다 (§3-3).

**1순위 — 사업자 단위 개폐업 이력.** 지금은 "칸에서 2건 닫혔다"만 알고 누가·언제·몇 년 만에 닫혔는지 모릅니다. 생존분석(Cox)으로 바꿀 수 있으면 "업력 3년차 위험 구간" 같은 실행 가능한 결론이 나옵니다.

**2순위 — 상권 단위 임대료.** 현재 결론의 핵심 변수인 "점포 규모"가 왜 위험한지 설명이 없습니다. 큰 칸 = 임대료 높은 목 = 고정비 부담일 가능성이 큽니다. 지역별 임대료 데이터(서울 부분)를 상권 좌표에 공간 결합하면 규모 효과가 임대료로 얼마나 흡수되는지 볼 수 있습니다. **다만 현재 확보된 임대료 데이터는 자치구 단위라 상권 간 변별력이 없습니다** — 상권/행정동 단위가 필요합니다.

**2.5순위 — `운영_영업_개월_평균` 을 피처로 추가.** 상권변화지표 파일에 들어 있고, **영업 중인 점포**로 만들어져 라벨과 원천이 달라 누수가 아닙니다. 단변량 AUC 0.538 로 약하지만 5분위 순감소율이 29.9% → 22.2% 로 단조 감소하고, log_점포수와 상관이 −0.085 라 규모의 대리변수도 아닙니다. 이번 모형에는 넣지 않았습니다.

**3순위 — 배달 플랫폼 매출 비중.** 2023~2026 구간의 외식업 폐업은 배달 의존도와 얽혀 있을 가능성이 높은데, 현재 데이터에 없습니다.

**4순위 — 준실험 설계.** 자치구별 지원사업 시행 시점 차이를 이용한 이중차분(DID)이나 이벤트 스터디. 지금은 관측 데이터 매칭이라 미관측 교란을 배제할 수 없습니다.

### 8-5. 용어 한 줄 사전

| 용어 | 한 줄 설명 |
|---|---|
| **칸** | 분석의 최소 단위 = (상권 × 업종 × 분기) 하나. 예: "역삼동 골목상권의 한식음식점, 2025년 3분기" |
| **순감소** | 그 칸에서 다음 분기 개업 < 폐업. 이 프로젝트의 라벨 y |
| **처리군 / 대조군** | 처리군 = 한식음식점 칸, 대조군 = 조건이 비슷한 타 업종 칸 |
| **공변량** | 처리군과 대조군에서 똑같이 맞춰줄 조건 4개: log 점포수 · log 유동인구 · log 면적 · log 집객시설 |
| **공통지지 영역** | 처리군과 대조군의 성향점수 분포가 겹치는 구간. 여기 밖은 애초에 비교 상대가 없어 잘라냅니다 |
| **캘리퍼** | 짝을 지을 때 허용하는 최대 거리(성향점수 표준편차의 0.2배). 넘으면 짝을 안 짓습니다 |
| **train/serve skew** | 학습 때와 예측 때 피처를 다르게 만들어서 생기는 조용한 오류. `config.build_features()` 로 한 코드만 쓰게 막았습니다 |
| **누수(leakage)** | 미래 정보가 학습에 섞여 성능이 가짜로 높아지는 것. 20254 를 학습에서 뺀 이유 |
| **ε² (엡실론 제곱)** | Kruskal-Wallis 의 효과크기. 0.01 작음 / 0.06 중간 / 0.14 큼. p 는 "차이가 있나", ε² 는 "쓸 만한 크기인가"에 답합니다 |
| **동질성(homogeneity)** | 층을 나눠도 효과가 같은가. 같아야 평균 하나로 요약할 수 있습니다. Woolf 검정으로 판정하며, 여기서는 p 가 크기를 바랍니다 |
| **선택 효과** | 여러 후보 중 "가장 높은 것"을 고르는 행위 자체가 만드는 격차. 진짜 차이가 0 이어도 생깁니다. 순열검정으로 크기를 잽니다 |
| **Lift** | (찍은 집단의 실제 발생률) ÷ (전체 평균 발생률). 1.0 = 무작위와 같음, 1 미만 = 무작위보다 못함 |
